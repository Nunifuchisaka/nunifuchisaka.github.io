GlossySkin

凪 -Nagi- のツヤ肌マスク

しっとり照る肌に。アバター付属のMatCapマスクを差し替えるだけで、夜の灯りや逆光を拾って脚や肩、鎖骨がつやりと光ります。

マスク2種 高精細マスク ツヤ量スライダー付き
BOOTHで入手する 特徴を見る
Features

差し替えるだけで、肌に照りが乗る

主役はマスク画像です。スライダーは「その場で加減を変えたい人向けのおまけ」なので、使わずマスクの差し替えだけでも成立します。

ツヤ肌マスク2種

「控えめ（soft）」と「しっかり（strong）」の2バリエーション。同じ差し替え作業で、照りの入り方を選べます。

高精細マスク

凪に付属のマスクより描き込みが細かく、照りの境目がなめらかに出ます。

差し替えるだけ

lilToonの「MatCap」の「マスク」の欄に画像を入れるだけです。改変の知識は要りません。lilToonは凪に付属のマテリアルで使われているシェーダーなので、追加の導入も不要です。

ツヤ量スライダー（おまけ）

VRChatのメニューにラジアルスライダーが増え、ツヤの強さを0〜100%でその場で変えられます。設定した値は保存され、次回ログイン後もそのまま使えます。あくまでおまけの機能です。

Setup

使い方

4ステップで導入できます。改変の知識は要りません。

unitypackageをインポートする

Unityのプロジェクトに、本商品のunitypackageをインポートします。

bodyマテリアルを複製する

凪のbodyマテリアルを複製し、複製した方をbodyメッシュに割り当てます。

付属マテリアルを直接編集すると、アバターの更新時に設定が消えるためです。

MatCapの「マスク」に設定する

複製したマテリアルのlilToonの設定画面で「MatCap」を開き、「マスク」の欄に本商品のマスク画像を設定します。

soft と strong を見比べる

soft と strong を入れ替えて見比べ、好みの方を選んでください。

おまけのスライダーを使う場合は、GlossySkinプレハブをアバターの直下に置くだけです（Modular Avatarの導入が必要です）。

おまけギミックの仕様 Modular Avatar
項目内容
パラメータ名GlossySkin
型Float（同期あり・保存あり）
既定値0.6
操作方法VRChatのメニューのラジアルスライダー。ツヤの強さを0〜100%で変更できます
消費する同期パラメータ8bit（Float 1つ分）
必要な依存Modular Avatar（無料）が別途必要です
対象パスnagi_body

おまけのスライダーは、bodyメッシュのオブジェクト名が初期状態（nagi_body）であることを前提にしています。改変で名前を変えたり階層を移動したりしている場合、エラーは出ませんが動作しません。

動作環境：VRChat PCアバター（Avatar SDK3）向け。対応アバターは凪 -Nagi-（rio3d様）です。lilToonは凪に付属のマテリアルで使われているシェーダーのため追加の導入は不要で、Modular Avatarはおまけのスライダーを使う場合のみ必要です。Unity 2022.3.22f1 で動作を確認しています。
Notes

注意点

購入前に確認してください。

凪 -Nagi- 専用です

本商品は「凪 -Nagi-」（rio3d様）専用です。肌のUV配置に合わせて描いているため、他のアバターでは正しく機能しません。

凪 -Nagi-【オリジナル3Dモデル】

アバター本体・マテリアルは含まれません

アバター本体、およびマテリアルは含まれません。マスク画像とおまけのギミックのみの商品です。

非公式の対応商品です

本商品は個人が制作した非公式の対応商品です。本商品についてのお問い合わせをrio3d様へ送ることはおやめください。

おまけのスライダーは nagi_body 前提です

おまけのスライダーは、bodyメッシュのオブジェクト名が初期状態（nagi_body）であることを前提にしています。改変で名前を変えたり階層を移動したりしている場合、エラーは出ませんが動作しません。

同期パラメータを8bit使用します

おまけのスライダーは、アバターの同期パラメータを8bit（Float 1つ分）使用します。

Modular Avatarが別途必要です

おまけのスライダーの利用には、Modular Avatar（無料）が別途必要です。

GlossySkin / 凪 -Nagi- のツヤ肌マスク

凪 -Nagi-（rio3d様）専用のツヤ肌マスクテクスチャ。マスク2種と、ツヤの強さを変えられるおまけのスライダーを同梱しています。 本ページは商品に同梱のドキュメントを元にした説明書です。
