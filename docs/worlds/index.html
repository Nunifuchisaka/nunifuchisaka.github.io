お気に入りワールド

好きなワールドや、案内でよく行くワールドを紹介します。

はじめての方は、はじめてのVRChat へ

のんびり過ごすなら

  • Rainy Skyline - 雨の摩天楼

    作者: ˖Vera˖ / 対応: PC · Quest

    雨の降る夜の街と摩天楼を見下ろす、居心地のよい部屋。映画やパーティーゲーム、カクテルバー、ペン、写真撮影まで、友だちとゆっくり過ごせます。

    VRChat の公式サイトで見る: Rainy Skyline - 雨の摩天楼 （新しいタブで開きます）

  • [JP] NDC Library

    作者: nemurigi

    日本十進分類法（NDC）の分類番号が並ぶ、静かな図書館のワールド。落ち着いて話したいときに。

    VRChat の公式サイトで見る: [JP] NDC Library （新しいタブで開きます）

物語や音楽を体験するなら

  • Project Lost Worlds

    作者: Fins

    宇宙船アストリア号に乗って、遠い月エリオスへ旅する映像体験（2部作の1作目、約1時間）。日本語にも対応しています。定員は6人で、入る前にワールドを先に読み込んでおくよう案内されています。

    VRChat の公式サイトで見る: Project Lost Worlds （新しいタブで開きます）

  • Undestined - yosumi（Music Experience World）

    作者: MIGIRI Inc

    クリエイティブスタジオ MIGIRI と、バーチャルシンガー yosumi による体験型の音楽ワールド。ワールドの音量は 80% 以上がおすすめとされています。

    VRChat の公式サイトで見る: Undestined - yosumi（Music Experience World） （新しいタブで開きます）

  • Half empty

    作者: yuri_ts

    「風をつかまえたんだ」。光の差す部屋で、粒子や流体のシミュレーションが風のように舞うワールド。

    VRChat の公式サイトで見る: Half empty （新しいタブで開きます）

  • _Let Go / 手放す

    作者: _you5248

    目を覚ますと白い部屋にいて、散らばったかけらをひとつずつ拾い集めていく、物語のワールド。

    VRChat の公式サイトで見る: _Let Go / 手放す （新しいタブで開きます）

  • TITANIC: Beyond Reality - Sinking Experience

    作者: CabaBear

    タイタニック号に乗り込み、華やかな船内と、沈没したあの夜を体験できるワールド。

    VRChat の公式サイトで見る: TITANIC: Beyond Reality - Sinking Experience （新しいタブで開きます）
