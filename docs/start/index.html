はじめてのVRChat

これからVRChatを始める人に向けて、遊べる機器と、最初にすること、知っておくと楽なことをまとめました。VRゴーグルがなくても始められます。

2026年11月時点の内容です。VRChatの画面や名前は変わることがあります。

遊べる機器

  • VRゴーグル

    Meta Quest なら、ゴーグルだけで遊べます。ゲーム用のPCとつなぐと、PC向けのワールドやアバターも使えます。

    使っている機材を見る

  • パソコン

    ゴーグルなしで、キーボードとマウスで遊べます（デスクトップモード）。Steam から入れます。

  • スマホ

    Android と iPhone 向けのアプリもあります。スマホに対応していないワールドやアバターもあります。

最初にすること

  1. アカウントを作る

    VRChat の公式サイトで、VRChat アカウントを作ります。Steam や Meta のアカウントでも入れますが、VRChat アカウントならどの機器でも同じアカウントを使えます。

  2. アプリを入れる

    Quest は Meta Horizon Store、パソコンは Steam から入れます。無料です。

  3. アバターを選ぶ

    最初は、VRChat に用意されたアバターから選びます。メニューのアバター一覧から、気に入ったものを選んでください。

  4. 操作に慣れる

    最初に入るホームで、移動、メニューを開く、マイクのオンオフを試します。

  5. 人のいる場所へ行く

    初心者向けのワールドや、知り合いのいるところへ行ってみます。案内してくれる人がいると、早く慣れます。

知っておくと楽なこと

インスタンス
同じワールドでも、部屋（インスタンス）が分かれています。Public は誰でも、Friends+ はフレンドとそのフレンド、Friends はフレンドだけ、Invite は招待された人だけが入れます。
マイクのミュート
マイクは周りの音を拾いやすいので、話さないときはミュートにしておくと安心です。
セーフティ設定
知らない人のアバターの見え方や、声の大きさを変えられます。重いアバターや大きな音が気になるときに使います。
ブロックと通報
嫌なことをされたら、その人のプロフィールからブロックできます。ブロックすると、お互いに見えなくなり、声も聞こえなくなります。
トラストランク
遊んでいるうちにランクが上がります。自分のアバターやワールドをアップロードするには、New User 以上になる必要があります。
Quest と PC
Quest だけで遊ぶときは、Quest に対応したアバターだけが本来の姿で見えます。対応していないアバターは、代わりの姿で表示されます。

マナー

  • 初めて会った人に、いきなり触れたり、近づきすぎたりしない。
  • 入口の看板など、ワールドのルールを読む。
  • 写真を載せるときは、写っている人に聞く。
  • 周りに人がいるときは、大きな音や光るエフェクトを控えめにする。
