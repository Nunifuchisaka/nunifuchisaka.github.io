はじめてのVRChat

これからVRChatを始める人に向けて、遊べる機器と、最初にすること、知っておくと楽なことをまとめました。VRゴーグルがなくても始められます。

2026年11月時点の内容です。VRChatの画面や名前は変わることがあります。

遊べる機器

  • VRゴーグル

    Meta Quest なら、ゴーグルだけで遊べます。ゲーム用のPCとつなぐと、PC向けのワールドやアバターも使えます。

    使っている機材を見る

  • パソコン

    ゴーグルなしで、キーボードとマウスで遊べます（デスクトップモード）。Steam から入れます。性能が足りないときや Mac のときは、GeForce NOW などで遊べます。

    性能の低いパソコンや Mac で遊ぶ

  • スマホ

    Android と iPhone 向けのアプリもあります。スマホに対応していないワールドやアバターもあります。

性能の低いパソコンや Mac で遊ぶ

VRChat のパソコン版は Windows 向けで、動かすにはある程度の性能が要ります。性能が足りないパソコンや Mac でも、GeForce NOW を使えば遊べます。VRChat は 2024年11月から GeForce NOW に対応しています。

しくみ
GeForce NOW は、NVIDIA のクラウドゲームのサービスです。ゲームは NVIDIA の高性能なパソコンで動き、その映像が手元に届きます。手元の機器は映像を映して操作を送るだけなので、性能の低いパソコンや Mac、Chromebook、スマホでも遊べます。
遊べる形
デスクトップモード（キーボードとマウス）だけです。VRゴーグルを使う遊び方はできません。Webカメラを使う機能も使えません。
用意するもの
GeForce NOW のアカウント、Steam のアカウント、VRChat のアカウントと、安定したネット回線です。GeForce NOW では Steam 版の VRChat を動かします。回線は、有線か 5GHz の Wi-Fi が安心です。
料金
無料のプランもありますが、1回に遊べる時間が短く、混んでいると順番待ちになります。長く遊ぶなら有料のプランにします。料金やプランは変わるので、公式サイトで確かめてください。

GeForce NOW で始める

  1. GeForce NOW の公式サイトでアカウントを作り、アプリを入れます。ブラウザからも遊べます。
  2. GeForce NOW で VRChat を探して、プレイを押します。
  3. Steam のアカウントでログインして、VRChat を起動します。
  4. VRChat のアカウントでログインします。
  5. 話すときは、GeForce NOW にマイクの使用を許可します。Mac では、システム設定の「プライバシーとセキュリティ」→「マイク」で許可します。

Mac で直接動かす（SteamAC Lite・実験版）

Apple Silicon（M1 以降）の Mac なら、SteamAC Lite というアプリを使うと、Mac で直接遊べるかもしれません。Mac の中で SteamOS（Steam を動かすための OS）を動かし、その上で Steam 版の VRChat を動かすアプリです。GeForce NOW と違い、Mac そのものの性能で動きます。

  • 個人が作っている実験版です。Valve や VRChat の公式のものではありません。
  • 必要なもの：Apple Silicon（M1 以降）の Mac、macOS 15.5 以降、メモリ 8GB 以上、空き容量 20GB ほど（入れるゲームの分は別に要ります）。Intel の Mac では使えません。
  • 作者の M1・メモリ 8GB の Mac で、VRChat が動いたと書かれています。重いワールドやアバター、長い時間遊んだときの安定、すべての Mac で動くかは、まだ確かめられていません。
  • Apple の公証を受けていないため、初めて開くときに macOS の確認が出ます。入手先を確かめたうえで、自分の判断で開いてください。

最初にすること

  1. アカウントを作る

    VRChat の公式サイトで、VRChat アカウントを作ります。Steam や Meta のアカウントでも入れますが、VRChat アカウントならどの機器でも同じアカウントを使えます。

  2. アプリを入れる

    Quest は Meta Horizon Store、パソコンは Steam から入れます。無料です。

  3. アバターを選ぶ

    最初は、VRChat に用意されたアバターから選びます。メニューのアバター一覧から、気に入ったものを選んでください。

  4. 操作に慣れる

    最初に入るホームで、移動、メニューを開く、マイクのオンオフを試します。

  5. 人のいる場所へ行く

    初心者向けのワールドや、知り合いのいるところへ行ってみます。案内してくれる人がいると、早く慣れます。

マイクの設定

VRChat で話した声は、マイク → Windows → VRChat → 相手 の順に届きます。どこか1か所でも止まると、声は届きません。声が届かない、小さい、途切れるときは、この順に確かめてください。

  1. マイクゴーグルのマイク、ヘッドセット、卓上のマイク
  2. Windows使うマイク・入力の音量・マイクへのアクセス許可
  3. VRChat使うマイク・音量・ノイズの抑制・拾い始める大きさ・ミュート
  4. 相手相手の耳に届く

Quest だけで遊ぶときは、Windows の設定は関係ありません。Quest の設定で、VRChat にマイクの使用が許可されているかを確かめます。

ひとりで確かめる

  • 画面の端に、斜線の入ったマイクのアイコンが出ているときはミュート中です。
  • 鏡の前で話すと、口が動くアバターなら、声に合わせて口が動きます。口が動けば、声は VRChat まで届いています。
  • Windows のサウンドの設定で、話すと入力のバーが動くかを見ます。動かなければ、Windows までも届いていません。

VRChat の中の設定

メインメニューの Settings の「Audio & Voice」に、マイクの項目があります。クイックメニューの設定からも変えられます。日本語表示にしているときは、項目の名前も日本語になります。

  1. 使うマイク（Microphone）：声を拾うマイクを選びます。Quest Link でゴーグルのマイクを使うなら「Oculus Virtual Audio Device」の入った名前を選びます。一覧に目当てのマイクが無いときは、Windows がマイクを見つけられていないので、下の Windows の設定を確かめます。
  2. マイクの音量（Mic Output Volume）：相手に届く自分の声の大きさです。ふつうは 100% のままにします。音が割れると言われたら下げます。小さいと言われたら、先に Windows の入力の音量を確かめます。
  3. ノイズの抑制（Noise Suppression）：パソコンのファンやキーボードの音を減らします。声がこもる、途切れると言われたらオフにします。NVIDIA Broadcast など別のノイズ除去を使うときも、二重にかからないようにオフにします。
  4. 声を拾い始める大きさ（Mic Activation Threshold）：この大きさより小さい音は送りません。話すとバーが動くので、話しているときは線を超え、黙っているときは線より下になる位置にします。上げすぎると、話し始めや小さな声が切れます。5% ほどから試します。
  5. ミュートのしかた（Microphone Behaviour）：Toggle は押すたびにオンとオフが切り替わり、Push to Talk は押している間だけ声が届きます。デスクトップモードでは V キーです。

Windows の設定

パソコンで遊ぶとき（PCVR とデスクトップモード）は、Windows の設定も確かめます。Windows 11 の画面で説明します。Windows 10 にも、ほぼ同じ項目があります。

  1. 使うマイク：VRChat で使うマイクを選びます。VRChat の「Microphone」と同じものにしておくと迷いません。
  2. 音量：話すと、下のバーが動きます。動かないときは、マイクが声を拾っていません。音量は 80〜100 ほどにして、声が小さいと言われたらここを上げます。
  1. マイクへのアクセス：オフだと、どのアプリもマイクを使えません。
  2. アプリにマイクへのアクセスを許可する：オンにします。
  3. デスクトップ アプリにマイクへのアクセスを許可する：Steam から入れた VRChat は「デスクトップ アプリ」です。ここがオフだと、VRChat はマイクを使えません。見落としやすいところです。

さらに細かい設定は、「設定」→「システム」→「サウンド」の下のほうにある「サウンドの詳細設定」（Windows の版によっては「その他のサウンド設定」）を開き、「録音」タブでマイクを選んで「プロパティ」を押すと出ます。

  1. このデバイスを聴く：チェックがあると、自分の声が自分のイヤホンやスピーカーから聞こえます。自分の声が遅れて聞こえるときは、ここを外します。
  2. マイク：「設定」の音量と同じものです。
  3. マイク ブースト：マイクによってはあります。上げると声が大きくなりますが、周りの音も大きく拾います。声が小さいときは、先に「マイク」を上げます。
  4. 排他的に制御：チェックがあると、ほかのアプリ（Discord など）がマイクを使っている間、VRChat がマイクを使えないことがあります。声が届かないときは、外して試します。

PCVR では、SteamVR を起動すると、Windows の既定のマイクがゴーグルのマイクに切り替わることがあります。ゴーグルではなく別のマイクを使いたいときは、SteamVR の設定の「オーディオ」で、SteamVR を使っている間のマイクを選びます。

よくある困りごと

声がまったく届かない

VRChat でミュートになっていないか → VRChat の「Microphone」で選んだマイク → Windows のマイクのアクセス許可（とくにデスクトップ アプリ）→ Windows の入力のバーが話すと動くか、の順に確かめます。

声が小さい

Windows の入力の音量と、VRChat の Mic Output Volume を確かめます。マイクと口が離れていないかも見ます。相手が、あなたの声だけを個別に小さくしていることもあります。

声が途切れる、話し始めが切れる

Mic Activation Threshold を下げます。それでも切れるときは、Noise Suppression をオフにします。無線でつないでいるときは、電波の具合でも途切れます。

雑音や息の音が入る

Noise Suppression をオンにして、Mic Activation Threshold を少し上げます。マイク ブーストを下げ、マイクを口の正面から少しずらします。

相手の声が、自分の声に混ざって返る

スピーカーで聞いていると、相手の声をマイクが拾って送り返します。イヤホンやヘッドホンで聞きます。自分の声が自分に聞こえるときは、Windows の「このデバイスを聴く」を外します。

ゴーグルを替えたら声が届かなくなった

VRChat の「Microphone」と Windows の入力で、新しいゴーグルのマイクを選び直します。PCVR では、SteamVR の設定の「オーディオ」でも、SteamVR を使っている間のマイクを選べます。

VRゴーグルを PC につなぐ（PCVR）

Meta Quest や PICO を PC につなぐなら、無線の Virtual Desktop がおすすめです。有料ですが、新品の Meta Quest 3 / 3S を Meta の紹介プログラムで始めると 30ドル相当のストア残高が付くので、その残高で買えます。PC につなぐと、PC 向けのワールドやアバター、下の便利なアプリが使えます。

Virtual Desktop（おすすめ）
無線でつなぐ有料のアプリです。Meta Quest でも PICO でも使えます。画質と安定がよく、設定も細かく変えられるので、無線で遊ぶ人の定番です。PC には Virtual Desktop Streamer を入れ、PC はルーターに有線 LAN でつなぎ、ゴーグルは 5GHz 以上の Wi-Fi につなぎます。ストアごとに別売りで、Meta Horizon Store で買ったものは PICO では使えません（Meta Horizon Store では 24.99ドル）。

Meta Quest の場合

Quest Link（ケーブル）
無料です。PC に Meta Quest Link アプリを入れ、USB-C ケーブル（USB 3）でつなぎます。映像が安定し、遅れも少ないですが、ケーブルが動きのじゃまになります。
Air Link
無料です。Quest Link と同じ Meta Quest Link アプリで、Wi-Fi を使って無線でつなぎます。
Steam Link
無料です。Valve のアプリで、Meta Quest Link アプリを使わずに、無線で SteamVR に直接つなぎます。

PICO の場合

PICO Connect
PICO 公式の無料アプリです。USB-C ケーブルでも Wi-Fi でもつなげます。PC は Windows 10（22H2 以降）か 11、ゴーグルは PICO OS 5.11.2 以降が要ります。古い PICO OS では、前のアプリ「Streaming Assistant」を使います。
Steam Link
無料です。2025年9月から PICO のストアでも配られています（PICO 4 Ultra、PICO 4 / 4 Pro、Neo3）。ただし PICO では、ハンドトラッキングや体のトラッキングを SteamVR に送りません。

無線で遊ぶときは、家の Wi-Fi が快適さを大きく左右します。PCVR のための Wi-Fi・LAN 環境の作り方（note）（新しいタブで開きます）にまとめています。

Meta Quest なら、Virtual Desktop を紹介プログラムの特典で買える

  • Meta の紹介プログラムでは、紹介リンクから新品の Meta Quest 3 / 3S を買って使い始めると、紹介された人と紹介した人の両方に、30ドル相当の Quest cash（Meta Horizon Store で使える残高）が付きます。
  • この残高で、Virtual Desktop（24.99ドル）の代金をまかなえます。現金ではなく、ストアでだけ使えます。
  • 条件：新品の Quest 3 / 3S で、その Meta アカウントで初めての Quest であること。ゴーグルの初期設定（有効化）の前に、紹介リンクを開いて承認しておきます。18歳以上が対象です。条件は変わることがあるので、Meta の公式ヘルプで確かめてください。
  • 下のリンクはぬにふちさかの紹介リンクです。ここから使うと、ぬにふちさかにも同じ特典が付きます。

PCVR で入れておくと便利なアプリ

XSOverlay
VR の中に PC の画面やウィンドウを出して、コントローラーでクリックや文字入力ができます。左の手首には、コントローラーやトラッカーの電池の残りも出ます。ゴーグルを外さずに Discord を見たり、調べ物をしたりできます。Steam で 1,010円（早期アクセス）。Windows 10 / 11 用。
OVR Advanced Settings
SteamVR の細かい設定をまとめて変えられます。ボタンを握って手を動かすと自分の位置ごと動かせる Space Drag（座ったまま、寝転んだまま視点の高さを変えられる）、床の高さを合わせる Fix Floor、マイクの Push-to-Talk、画面の明るさなど。Steam で 920円。画面は英語だけです。
  • どちらも SteamVR の上で動くアプリです。PC につないで、SteamVR 経由で VRChat を遊んでいるときに使えます。ゴーグルだけで遊ぶとき（PC につながないとき）は使えません。Meta Quest でも PICO でも、PC につないでいれば使えます。
  • そのままだと、SteamVR を起動するたびに自分で開く必要があります。SteamVR の設定の「スタートアップ / シャットダウン」→「スタートアップオーバーレイアプリを選択」で両方をオンにすると、SteamVR と一緒に立ち上がります。

知っておくと楽なこと

インスタンス
同じワールドでも、部屋（インスタンス）が分かれています。Public は誰でも、Friends+ はフレンドとそのフレンド、Friends はフレンドだけ、Invite は招待された人だけが入れます。
マイクのミュート
マイクは周りの音を拾いやすいので、話さないときはミュートにしておくと安心です。
セーフティ設定
知らない人のアバターの見え方や、声の大きさを変えられます。重いアバターや大きな音が気になるときに使います。
ブロックと通報
嫌なことをされたら、その人のプロフィールからブロックできます。ブロックすると、お互いに見えなくなり、声も聞こえなくなります。
トラストランク
遊んでいるうちにランクが上がります。自分のアバターやワールドをアップロードするには、New User 以上になる必要があります。
Quest と PC
Quest だけで遊ぶときは、Quest に対応したアバターだけが本来の姿で見えます。対応していないアバターは、代わりの姿で表示されます。

マナー

  • 初めて会った人に、いきなり触れたり、近づきすぎたりしない。
  • 入口の看板など、ワールドのルールを読む。
  • 写真を載せるときは、写っている人に聞く。
  • 周りに人がいるときは、大きな音や光るエフェクトを控えめにする。
