Avatar Tips #6

How the Animator works

Press a menu item, and a hat appears. Make a hand sign, and your expression changes. In between, a chain of parts does the work, one after another: parameters, the Animator, states, transitions and animation clips. Before you build your own gimmicks, this tip explains what each part does and where you set it up.

Read this when

  • You want to build your own gimmicks, but the Animator makes no sense when you open it.
  • You've seen names like FX and Gesture, but you don't know how they differ.
  • You want to know how parameters, the menu and the Animator connect.
  • You added a gimmick someone else made, but you don't know what's going on inside it.

From pressing the menu to a change you can see

Almost every gimmick on a VRChat avatar works the same way. In this tip, the example is a gimmick that shows and hides a hat from the menu. Names are examples.

  1. Press the menuThe "Hat" Toggle in the Expressions Menu
  2. The parameter changesHat goes from false to true
  3. The transition's condition is metThe condition is "Hat is true"
  4. The state changesFrom Hat_OFF to Hat_ON
  5. The clip's values are writtenThe hat's Is Active becomes 1
  6. What you see changesThe hat appears

The menu only changes a parameter's value. It doesn't change how anything looks. What changes the look is the animation clip the Animator plays. The menu and the Animator are linked by the parameter's name.

Gimmicks that react to hand signs or to touch work the same way. The first step changes from "press the menu" to "your hand shape changes" or "a hand touches your head." From the parameter onward, the flow is the same.

When a gimmick doesn't work, check each step from left to right to find where the flow stops. #12 When a gimmick doesn't work explains how to check.

Words used in this tip

First, let's make sure we mean the same thing by each word. Names on Unity's screens are written as they appear there.

Animator
The system that looks at parameters and decides which animation to play right now. The Animator component on the top object of your avatar runs it.
Animator Controller (controller)
The file that holds what's inside the Animator. Its extension is .controller. It contains layers, states, transitions and parameters.
Playable Layers
The slots VRChat gives each avatar for controllers. They include FX, Gesture and others.
Layer
A level inside a controller. You usually make one per gimmick. This is not the same thing as Playable Layers.
State
A box that stands for the current condition, like "the hat is showing." Each state holds one clip.
Transition
An arrow from one state to another. When its condition is met, the Animator moves to the state the arrow points to.
Parameter
A value the Animator looks at. There are Bool (on or off), Int (whole number) and Float (decimal number).
Animation clip
A file that says which property of which object to set to which value. Its extension is .anim. #7 Making animations explains how to make one.
Expression Parameters
A list that tells VRChat which parameters your avatar uses. Here you also decide whether each value is remembered and whether it's sent to other people.
Expressions Menu
The contents of the menu you open in VRChat (the Action Menu). Pressing an item changes a parameter's value.

What the Playable Layers do

A VRChat avatar has five slots for controllers. These are called Playable Layers. Select your avatar in the Hierarchy (the object with the VRC Avatar Descriptor), and look at "Playable Layers" in the VRC Avatar Descriptor in the Inspector.

The five slots are stacked in this order: Base, Additive, Gesture, Action, FX. When two slots move the same thing, the later one (closer to FX) wins.

Base
Movement such as walking, running and crouching. It only moves bones (Transforms). You usually leave it alone.
Additive
Motion added on top of Base, such as breathing. It only moves Humanoid bones. You usually leave it alone.
Gesture
Finger shapes for hand signs, and tail or ear motion. It only moves bones.
Action
Motion for the whole body, such as emotes. Normally this slot has no effect (its Weight is 0), and it's turned on only when it's used.
FX
Everything except bone motion: turning objects on and off, BlendShapes (expressions and body shape), materials and more. Almost every gimmick you build goes here.
Sitting, TPose, IKPose
Motion for sitting, and poses used to measure your body size and how your joints bend. They're listed below Playable Layers. You usually leave them alone.

There's a reason to drive the look from FX. BlendShapes and materials moved from any slot other than FX are not copied to your reflection (the avatar you see in a mirror). Everything moved from FX is copied.

On the other hand, Humanoid bones (arms, legs, head, fingers and so on) don't move from FX. Hand shapes and poses are moved from Gesture or Action. Even when a hand sign changes your expression, the work is split: the expression (BlendShape) is in FX, and the finger shape is in Gesture. #10 Changing expressions with hand gestures explains this in detail.

Avatars that aren't Humanoid (Generic avatars) only have three slots: Base, Action and FX.

  1. The Gesture slot. It holds a controller that makes the finger shapes for hand signs. Slots left at "Default" use VRChat's standard controller.
  2. The FX slot. Avatars you buy usually come with a controller here already, for expressions and such. Click the field to highlight the file in the Project window, and double-click it to open it in the Animator window.

Controllers, layers, states and transitions

You look inside a controller in the Animator window. Open it with Window → Animation → Animator, then select (or double-click) a controller file in the Project window to show what's inside.

To make your own, right-click a folder in the Project window and choose Create → Animator Controller. If you make one per gimmick, it's easier to connect it to your avatar later with Modular Avatar.

At the top left of the Animator window are two tabs: Layers and Parameters. Choose Layers to see the list of layers. The states and transitions of the selected layer appear in the large area on the right (the graph).

Layer
A level for each gimmick. Add one with the + at the top left. Layers are calculated from top to bottom, and when two of them write the same thing, the lower layer wins. Every layer except Base Layer at the top starts with a Weight (how strongly it applies) of 0 when you add it. Click the gear to the right of the layer and set Weight to 1. If it stays at 0, the state will switch, but you won't see any change.
State
A box that stands for a condition, like "the hat is hidden" or "the hat is showing." Right-click an empty spot in the graph and choose Create State → Empty, or drag a clip file into the graph. When you select a state, Motion in the Inspector shows the clip it plays.
Default State (the orange state)
The first state the layer enters when it starts running. The first state you make turns orange. To change it, right-click a state and choose Set as Layer Default State. For an on/off gimmick, make the normal look (hat hidden) the Default.
Transition
An arrow from one state to another. To draw one, right-click a state, choose Make Transition, then click the destination state. Select the arrow to see its settings and Conditions in the Inspector.
Entry, Any State, Exit
Entry is the way in, and it connects to the Default State. Any State means "whichever state you're in now." An arrow drawn from it moves from anywhere once its condition is met. Exit is the way out. You can build an on/off gimmick without using Any State or Exit.
  1. Add one layer per gimmick. Press + at the top left and give it a name (Hat here).
  2. Click the gear to the right of the layer to see this. A newly added layer has a Weight of 0. Always set it to 1.
  3. The layer starts from the orange state. Here, Hat_OFF, where the hat is hidden, is the Default.
  4. Select an arrow to see its condition in the Inspector. The arrow there moves when Hat is true, and the arrow back moves when Hat is false.
SettingWhat it meansFor an on/off gimmick
Has Exit TimeWhen checked, the current clip plays until a set time (Exit Time) before moving on.Uncheck it, so it moves right away.
Transition DurationHow long it takes to blend from the previous state into the next one. If Fixed Duration is checked, it's in seconds. If not, it's a fraction of the clip's length.Set it to 0, so it switches instantly.
ConditionsThe conditions for moving. Add one with +, then choose a parameter and a value. If you add several, it moves only when all of them are met.There: Hat is true. Back: Hat is false.
Can Transition To SelfOnly arrows drawn from Any State have this. When checked, the Animator keeps re-entering the same state for as long as the condition is met.When you use Any State, you usually uncheck it.

#8 Building a menu toggle walks you through each transition setting.

To make your controller work on the avatar, it has to be added to the controller in the avatar's FX slot. With Modular Avatar's MA Merge Animator, it's added automatically when you upload, without editing the FX file of the avatar you bought. This series recommends this way. #8 Building a menu toggle shows the steps.

Parameters (Animator and Expression Parameters)

Parameters are values the Animator looks at. They're used in transition conditions and in Blend Trees (a way to mix clips based on a value).

You write each parameter in two places. One is the controller's Parameters tab (values the Animator looks at). The other is VRChat's Expression Parameters (values the menu can change, and that can be remembered or sent to other people). The two are linked by name. The names must match exactly, including uppercase and lowercase. Hat and hat are different parameters.

To add a parameter to the Animator, open the Parameters tab in the Animator window, press +, choose a type (such as Bool) and type a name. To make an Expression Parameters file, right-click in the Project window and choose Create → VRChat → Avatars → Expression Parameters. Avatars you buy usually come with one already.

TypeValuesSync costCommon uses
Booltrue (on) or false (off)1 bitShowing and hiding accessories or clothes. #8 Building a menu toggle
IntWhole numbers from 0 to 2558 bitPicking one of several outfits. #9 Switching in steps and changing gradually
FloatDecimals from -1.0 to 1.0 (0.0 to 1.0 with Radial Puppet)8 bitChanging color or size little by little by turning a dial. #9 Switching in steps and changing gradually
Trigger (Animator only)Becomes true for just a moment—VRChat's official docs recommend not using it. Use Bool, Int or Float instead.

As a rule, use the same type in the Animator as in Expression Parameters. If the types differ, VRChat converts the value. For example, if a parameter is a Bool in Expression Parameters but a Float in the Animator, true becomes 1.0 and false becomes 0.0. This is handy when you want to use an on/off value in a Blend Tree.

Each parameter in Expression Parameters has these settings.

Default
The value when the avatar loads or is reset. If the hat starts out not being worn, set it to false.
Saved
When checked, the value is remembered even when you change worlds or switch avatars. When unchecked, it goes back to Default each time.
Synced
When checked, the value is sent to other people. When unchecked, it changes only for you, and others don't see it change.

Synced parameters (with Synced checked) can use up to 256 bits in total. A Bool uses 1 bit, and an Int or a Float uses 8 bits.

Some parameters are filled in by VRChat (built-in parameters). Examples are GestureLeft and GestureRight for hand signs, and IsLocal, which tells whether this is your own avatar. You don't write these in Expression Parameters. Just add them to the Animator's Parameters with the same name and type, and you can use them. #10 Changing expressions with hand gestures explains the hand sign numbers.

#8 Building a menu toggle shows how to choose Saved, Synced and Default for your gimmick.

  1. The Animator's Parameters tab. A parameter that isn't here can't be chosen as a transition condition.
  2. The name in Expression Parameters. Make it exactly the same as the Animator parameter, including uppercase and lowercase. Copying and pasting the name helps you avoid mistakes.
  3. Saved: the value is remembered even when you change worlds.
  4. Synced: the value is sent to other people. When unchecked, others don't see it change.

Expressions Menu

The Expressions Menu is the contents of the menu you open in VRChat (the Action Menu). Each item in the menu (a Control) changes a parameter's value when you press or turn it.

To use it, put a Menu (the menu file) and Parameters (the Expression Parameters file) in the "Expressions" section of the VRC Avatar Descriptor. To make a menu file, right-click in the Project window and choose Create → VRChat → Avatars → Expressions Menu.

One menu can hold up to 8 items. If you need more, split them into another menu with a Sub Menu.

TypeWhat it doesParameter used
TogglePress it to set the Value. Press it again to go back.Bool (Int and Float also work)
ButtonPress it to set the Value. It goes back after a moment (about 1 second). It can't stay pressed.Bool, Int and others
Sub MenuOpens another menu. You can put menus inside a menu.Not required
Two Axis PuppetTilt the stick up/down and left/right to change two Floats between -1.0 and 1.0.2 Floats
Four Axis PuppetTilt up, right, down or left to change four Floats between 0.0 and 1.0, by how far you tilt.4 Floats
Radial PuppetTurn the round dial to change one Float between 0.0 and 1.0.1 Float

The Value of a Toggle or Button is the value written to the parameter when you press it. For a Bool, 1 means true. For an Int, it's a number. For example, if Value is 2, the parameter becomes 2, so you can build a menu that switches to outfit number 2.

  1. The name shown in the VRChat menu. Non-English text, such as Japanese, works too.
  2. The item type. For on/off, choose Toggle.
  3. The parameter whose value it changes. Choose from the parameters in Expression Parameters.

With Modular Avatar's MA Menu Item and MA Menu Installer, you can add items without editing your avatar's menu file. This series uses that way (#8 Building a menu toggle).

If you only want to turn clothes on and off, you can also use Modular Avatar's Create Toggle and skip making an Animator (#3 Dressing your avatar). The tips in this series build the Animator by hand, so you can see how it works.

Common problems and fixes

The state changes, but the look doesn't

What happens
When you press Play in Unity, the Animator window shows the state switching. But the hat doesn't appear.
Cause
The added layer's Weight is still 0. When you add a layer in Unity, it's created with a Weight of 0.
Fix
In the Layers tab of the Animator window, click the layer's gear and set Weight to 1.

Pressing the menu doesn't change the state

What happens
You press the menu item, but the Animator stays in the Default state.
Cause
The parameter names in Expression Parameters and the Animator don't match. A difference in uppercase and lowercase, or a space at the end of a name, is common. Sometimes the parameter was never added to the Animator.
Fix
Copy the name from Expression Parameters and paste it as the Animator parameter's name. Match the type too.

It switches late, or changes slowly

What happens
It switches a beat after you press the menu. It doesn't change instantly, but little by little.
Cause
The transition has Has Exit Time checked, or its Transition Duration isn't 0.
Fix
Select the arrow, uncheck Has Exit Time, and set Transition Duration to 0. Also see #8 Building a menu toggle.

Hand shapes or poses don't move

What happens
You made an arm or finger shape in an FX clip, but it doesn't move in VRChat.
Cause
Humanoid bones (muscles) don't move from FX.
Fix
Move hand shapes with the Gesture controller, and whole-body motion with the Action controller.

Only your reflection doesn't change expression

What happens
Your expression changes when you look at yourself, but the avatar in the mirror doesn't change.
Cause
You're moving the expression BlendShapes from a slot other than FX (such as Gesture). BlendShapes and materials from slots other than FX aren't copied to the avatar in the mirror.
Fix
Move clips that change the look, such as expressions, into the FX controller.

You can see it, but others can't

What happens
The hat shows on your screen, but your friends say they can't see it.
Cause
Synced is unchecked for that parameter in Expression Parameters.
Fix
Check Synced and upload again. Other causes are listed in #12 When a gimmick doesn't work.

Things to watch out for

  • Before you edit the FX file of an avatar you bought, make a copy first. If you can, add your own controller separately with Modular Avatar. Then your gimmicks won't disappear when you update the avatar.
  • Don't put one controller into two slots (for example, Gesture and FX). VRChat's official docs also say this can cause major problems.
  • Don't make dead-end states. Parameters can change at any time. When you draw an arrow to a state, also draw one back.
  • Don't mix Write Defaults ON and OFF in the same controller. If you make both an on clip and an off clip, it works either way (#13 It looks different in Unity and VRChat).
  • Give parameters names that tell you which gimmick they belong to. If two gimmicks share a name, moving one also moves the other.

Summary

  • The menu only changes a parameter's value. What changes the look is the clip the Animator plays.
  • Drive the look (on/off, BlendShapes, materials) from FX. Humanoid bones don't move from FX.
  • A controller is made of layers, states and transitions. Set the Weight of each layer you add to 1.
  • Animator parameters and Expression Parameters are linked by name. Match them exactly, including uppercase and lowercase.
  • Next, you'll make the clips that go into states (#7 Making animations).
