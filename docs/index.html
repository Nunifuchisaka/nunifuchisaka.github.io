  • アバターギミック（アクセサリー） Regret 腕や足に付けた骨を振ると飛んでいき、床に残る。元の場所で触れると、また付く。
  • Blenderアドオン NuniAvatarToolkit 隠れメッシュの削除や服のフィットなど、アバター制作のメッシュ最適化をひとまとめに。無料。

  • オーバーレイアプリ（β版） KeyDisplay 押しているキーやマウスの操作を画面に出すオーバーレイ。Unity・Blenderの解説動画向け。
