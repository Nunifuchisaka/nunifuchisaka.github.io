このツールについて

zundamon-video は、ぬにふちさかが自分の YouTube チャンネルへの動画の投稿と分析のために、自分の PC で使う個人用のツールです。他の人には配布も提供もしていません。

Google のデータの利用

Google アカウントで許可されたとき、YouTube Data API と YouTube Analytics API、YouTube Reporting API を通じて、動画のアップロードとサムネイルの設定、動画の情報の編集、チャンネルと動画の情報の読み取り、分析データの読み取りを行います。

データの保存と共有

取得したデータと認証の情報は、利用者本人の PC の中だけに保存します。開発者のサーバーはなく、第三者へ送信、販売、共有はしません。Google から得たデータの利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

許可の取り消しとデータの削除

許可の取り消しは https://myaccount.google.com/permissions からいつでもできます。取り消すと、ツールはデータにアクセスできなくなります。PC に保存したデータは本人が削除できます。

YouTube API Services

このツールは YouTube API Services を使います。YouTube 利用規約 https://www.youtube.com/t/terms と Google プライバシーポリシー https://policies.google.com/privacy が適用されます。

zundamon-video Privacy Policy (English)

Last updated: 2026-11-06

About this tool

zundamon-video is a personal tool that Nunifuchisaka uses on their own PC to upload videos to, and analyze, their own YouTube channel. It is not distributed or provided to anyone else.

Use of Google data

When authorized through a Google account, the tool uses the YouTube Data API, YouTube Analytics API, and YouTube Reporting API to upload videos, set thumbnails, edit video information, read channel and video information, and read analytics data.

Data storage and sharing

Retrieved data and authentication information are stored only on the user's own PC. There is no developer server, and data is not sent, sold, or shared to third parties. Use of data obtained from Google complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at https://myaccount.google.com/permissions. After revocation, the tool can no longer access the data. Data saved on the PC can be deleted by the user.

YouTube API Services

This tool uses YouTube API Services. The YouTube Terms of Service https://www.youtube.com/t/terms and the Google Privacy Policy https://policies.google.com/privacy apply.
