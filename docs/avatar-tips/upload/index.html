アバター改変の解説 第2回

アップロードのしかた

買ったアバターを Unity に入れて、VRChat にアップロードするまでの流れです。シェーダーを入れる順番、VRChat SDK の Builder の見方、更新するときの注意、よくあるつまずきを、再現図つきで解説します。

公開 2026年11月3日 · 対象は VRChat SDK 3（Avatars）です。2026年11月時点の内容で、SDK が新しくなると画面が変わることがあります。

こんなときに読んでください

  • アバターを買ったけれど、どうやって VRChat で使えばいいか分からない。
  • Builder の画面に赤や黄色のメッセージが出て、何をすればいいか分からない。
  • 改変したアバターをアップロードし直したい。別のアバターとして分けたい。
  • アップロードしたのに、VRChat で見つからない。

アップロードまでの流れ

Unity と VCC（か ALCOM）を入れて、アバター用のプロジェクトを作ってあるところから始めます。まだのときは、第1回 VCC・ALCOM・Unity の入れ方を先に読んでください。

  1. シェーダーやツールを入れるlilToon など。アバターより先に
  2. アバターを入れる.unitypackage を読み込む
  3. シーンに置くPrefab を Hierarchy へ
  4. SDK でログインVRChat のアカウント
  5. Builder で確かめるエラーを直して公開
  6. VRChat で確かめるアバターの一覧から着る

アップロードに要るもの

VRChat のアカウント
VRChat のサイトで作ったアカウントでログインします。Steam や Meta のアカウントで遊んでいるときは、先に VRChat のアカウントとつないでおきます。
ランク「New User」以上
アップロードできるのは、ランク（Trust Rank）が「New User」以上のアカウントです。「Visitor」のあいだは、自分だけが見られるテスト（Build & Test）しかできません。アップロードできるようになると、メールで知らせが届きます。
アバターの利用規約
アバターや衣装ごとに、使ってよい範囲が決まっています。とくに「公開（Public）にしてよいか」は、配布ページや同梱の規約で確かめます。

シェーダーとアバターを入れる

アバターの説明書（README）に、先に入れるもの（シェーダーやツール）と、その順番が書いてあります。まずそれを読みます。

  1. 説明書に書いてあるシェーダー（lilToon、Poiyomi など）やツール（Modular Avatar など）を、アバターより先に入れます。VCC や ALCOM で入れられるものは、プロジェクトの管理画面から入れます。.unitypackage で配られているものは、次の手順と同じように読み込みます。
  2. アバターの .unitypackage を、Unity の Project ウィンドウにドラッグします。Assets → Import Package → Custom Package... から選んでも同じです。
  3. Import Unity Package の画面が出たら、そのまま「Import」を押します。
  4. 読み込みが終わったら、Console ウィンドウに赤いエラーが出ていないかを見ます。

先にアバターを入れてしまうと、シェーダーが無いため、アバターがピンク色になります。あとからシェーダーを入れれば、多くは直ります。

シーンに置く

  1. Project ウィンドウで、アバターのフォルダを開きます。アバターの名前の Prefab（青い箱のアイコン）を探します。
  2. Prefab を Hierarchy にドラッグして、シーンに置きます。アバターによっては、すぐ使えるシーンが入っていて、それを開くだけのものもあります。
  3. Hierarchy でアバターを選び、Inspector に「VRC Avatar Descriptor」があるかを見ます。売られているアバターは、ほとんど設定済みです。
  4. シーンに置くアバターは、アップロードするものだけにしておくと迷いません。いらないものは、選んで左上の印を外すと、隠せます。

VRChat SDK でログインする

  1. 上のメニューの VRChat SDK → Show Control Panel を押します。VRChat SDK の画面が開きます。
  2. 「Authentication」のタブで、VRChat のアカウントのユーザー名（かメールアドレス）とパスワードを入れて、ログインします。二段階認証を使っているときは、コードも入れます。
  3. 「Builder」のタブを開くと、シーンに置いたアバターが出ます。

Builder で確かめて、アップロードする

Builder のタブには、アバターの名前や公開の設定、確かめた結果（Validations）、アップロードのボタンが並んでいます。

  1. VRChat のアバターの一覧に出る名前です。あとから変えられます。
  2. Private は自分だけが使えます。Public にすると、ワールドの展示などから、ほかの人もそのアバターに着替えられます。売られているアバターは、規約で Public を禁止していることが多いので、ふだんは Private にします。
  3. 肌の出るところが多い、怖い表現があるなど、当てはまる注意の種類を選びます。見る人が、設定で隠せるようになります。
  4. 一覧に出る画像です。シーンの今の見た目を撮るか、画像のファイルを選びます。
  5. どの機器向けに作るかです。パソコン版だけなら Windows です。Quest やスマホでも見えるようにするには、その機器向けにも作ります（作れる条件があります）。
  6. 書いた情報が正しく、アップロードする権利を持っていることを確かめる印です。付けないとアップロードできません。
  7. 押すとビルドが始まり、終わると VRChat に送られます。下の Validations に赤いエラーがあると押せません。
  1. 名前を入れ、Visibility を選びます。迷ったら Private にします。
  2. 当てはまる Content Warnings を選び、Thumbnail（サムネイル）を撮ります。
  3. 下の Validations に出ているメッセージを、上から見ていきます（次の図）。
  4. 作る機器（Platforms）を選び、権利を確かめる印を付けて、「Build and Publish」を押します。
  5. ビルドとアップロードが終わるのを待ちます。アバターが大きいと、数分かかります。

アップロードの前に試したいときは、「Build & Test」を使います。自分だけが着られるテスト用のアバターとして、VRChat のアバターの一覧に出ます。ランクが「Visitor」でも使えます。

Validations（確かめた結果）の見方

Builder の下には、SDK がアバターを確かめた結果が並びます。メッセージには3つの種類があります。

色意味どうするか
赤（エラー）このままではアップロードできない問題直さないと「Build and Publish」が押せません。かならず直します。
黄（警告）アップロードはできるが、気をつけたいこと多くは、そのままでもアップロードできます。中身を読んで、直せるものは直します。
青・白（お知らせ）パフォーマンスランクなどの情報読むだけで大丈夫です。
  1. 「Auto Fix」のボタンがあるものは、押すと SDK が直してくれます。押す前に、何が変わるかをメッセージで読んでおきます。
  2. 「Select」を押すと、原因になっている物が Hierarchy で選ばれます。どこを直せばいいかが分かります。
  3. アバターの重さの目安です。ランクが低いと、見る人の設定によっては、ほかの人から見えないことがあります。詳しくは第4回 パフォーマンスランクと軽量化で解説しています。

更新するとき・別のアバターとして分けるとき

一度アップロードすると、アバターの一番上の物に「Pipeline Manager」というコンポーネントが付き、Blueprint ID（avtr_ で始まる番号）が書き込まれます。この番号が、VRChat の上のどのアバターかを表します。

同じ Blueprint ID のままアップロードすると、前のアバターが上書きされます。改変を直して入れ直すときは、このままで大丈夫です。

改変したものを別のアバターとして残したいときは、Pipeline Manager の「Detach」を押して番号を外してから、アップロードします。新しい番号が付きます。

  1. VRChat の上のどのアバターに入れるかを表す番号です。この番号のアバターが上書きされます。
  2. 番号を外します。このあとアップロードすると、新しいアバターとして入ります。
  3. 番号を新しく作ったり、決まった番号に入れ直したりするときに使います。ふだんは使いません。

アバターを Hierarchy で複製（Ctrl + D）すると、Blueprint ID もいっしょに写ります。そのままアップロードすると、もとのアバターが上書きされます。複製したほうは、先に Detach しておきます。

VRChat で確かめる

  1. VRChat を開き、メニューのアバターの一覧から、自分がアップロードしたアバターの欄を開きます。
  2. アップロードしたアバターを選び、着替えます。出ないときは、一覧を読み込み直すか、VRChat を開き直します。
  3. 鏡の前で、表情、ハンドサイン、揺れもの、メニューで動くものを一通り試します。
  4. ほかの人からどう見えるかも、ランクやセーフティの設定で変わります。気になるときは、フレンドに見てもらいます。

Unity の VRChat SDK の「Content Manager」のタブでも、アップロードしたアバターの一覧を見られます。

よくある困りごと

VRChat SDK のメニューや Builder が出ない

起きること
上のメニューに VRChat SDK が無い。Control Panel を開いても Builder が出ない。
直し方
Console に赤いエラー（コンパイルエラー）が出ていないかを見ます。入れたツールのエラーで、SDK が動かないことがあります。Unity のバージョンが VRChat の決めたものかも確かめます。

アップロードできない（ランク）

起きること
ログインはできたのに、アップロードできないと出る。
直し方
アカウントのランクが「New User」以上かを確かめます。「Visitor」のあいだは、Build & Test で自分だけ試せます。ランクは、VRChat で遊ぶうちに上がります。

「Build and Publish」が押せない

起きること
ボタンが灰色で押せない。
直し方
Validations に赤いエラーが無いか、権利を確かめる印を付けたかを見ます。押しても何も起きないときは、Unity を開き直します。

アバターがピンク色になる

起きること
Unity や VRChat で、アバターや服がピンク一色になる。
直し方
使っているシェーダーが入っていません。説明書にあるシェーダーを入れます。入れても直らないときは、マテリアルを選んで、シェーダーを選び直します。

別のアバターが上書きされた

起きること
新しいアバターをアップロードしたら、前のアバターが入れ替わった。
直し方
複製などで、同じ Blueprint ID のままアップロードしています。Pipeline Manager で Detach して、アップロードし直します。上書きされたほうは、もとのプロジェクトからもう一度アップロードします。

アップロードしたのに見つからない

起きること
アップロードが終わったのに、VRChat のアバターの一覧に出ない。
直し方
SDK でログインしたアカウントと、VRChat で遊んでいるアカウントが同じかを確かめます。SDK の Content Manager に出ているか、Console にエラーが出ていないかも見ます。SDK が古いときは、VCC や ALCOM で新しくします。

気をつけること

  • アバターや衣装の利用規約を守ります。Public にしてよいか、改変してよい範囲、ほかの人に配ってよいかは、モデルごとに違います。
  • Public のアバターは、ワールドの展示などから、ほかの人も着られるようになります。自分だけで使うものは Private にします。
  • Fallback（代わりの姿）は、ランクやセーフティの設定でアバターが見えない人に、代わりに見せる姿です。VRChat のアバターの一覧から設定できます。軽いアバターでないと設定できません。
  • 大きく改変する前に、プロジェクトのバックアップを取っておくと安心です。

まとめ

  • シェーダーやツールを先に入れ、そのあとアバターの .unitypackage を入れます。
  • VRChat SDK でログインし、Builder の Validations の赤いエラーを直してから、Build and Publish を押します。
  • 迷ったら Private にします。利用規約を確かめてから Public にします。
  • 同じ Blueprint ID のままだと上書きになります。別のアバターにするときは Detach します。

VRChat の公式の手順は、Creating Your First Avatar（英語）（新しいタブで開きます）にあります。
