アバター改変の解説

アバター改変でつまずきやすいところを、1回に1つずつ、仕組みと直し方まで解説する連載です。

Unity（Built-in Render Pipeline）で作る VRChat のアバターを前提に書いています。

  • 困りごとから探す
  • 順番に読む
  • VRChat 用語集

困りごとから探す

やりたいことや、困っていることから、読む回とその中の場所を探せます。

50 件

  • Mac で改変したい 第1回 VCC・ALCOM・Unity の入れ方
  • Unity がライセンスのエラーで開かない 第1回 VCC・ALCOM・Unity の入れ方
  • ツールやシェーダーをプロジェクトに足したい 第1回 VCC・ALCOM・Unity の入れ方
  • VRChat SDK のメニューや Builder が出ない 第2回 アップロードのしかた
  • 「Build and Publish」が押せない 第2回 アップロードのしかた
  • Validations に出たメッセージの意味が分からない 第2回 アップロードのしかた
  • アップロードしたら、別のアバターが上書きされた 第2回 アップロードのしかた
  • 改変したアバターを、上書きせずに別のアバターとして分けたい 第2回 アップロードのしかた

当てはまる困りごとがありません。ことばを短くするか、下の「順番に読む」から探してください。

順番に読む

はじめて改変するときは、第1回から順に読むのがおすすめです。部ごとに、前の回を読んだことを前提にしています。

第1部はじめる

道具を入れて、アバターをアップロードし、服を着せるまで。

  1. 第1回 VCC・ALCOM・Unity の入れ方 改変に要る Unity Hub と Unity、VCC と ALCOM。それぞれの役目とどちらを選ぶか、入れる手順をまとめました。 2026年11月3日
  2. 第2回 アップロードのしかた 買ったアバターを VRChat にアップロードするまで。シェーダーの順番、Builder の見方、更新と Blueprint ID をまとめました。 2026年11月3日
  3. 第3回 衣装を着せる 買った衣装を Modular Avatar で着せる手順と、体の突き抜けの直し方、メニューで服をオンオフする方法をまとめました。 2026年11月3日

第2部軽くして、多くの人に見てもらう

パフォーマンスランクと、Quest・スマホ対応。

  1. 第4回 パフォーマンスランクと軽量化 アバターのランクは、いちばん低い項目で決まります。上限の表と、AAO などで軽くする方法をまとめました。 2026年11月3日
  2. 第5回 Quest・スマホ対応 Quest やスマホの人に見てもらうには、軽くした Android 版が要ります。使えないもの、ランクの基準、作り方をまとめました。 2026年11月3日

第3部Animator でギミックを自分で作る

Animator のしくみから、オンオフ・段階・表情・触れて反応するギミック、動かないときの確かめ方まで。この順に読むと、自分でギミックを組めるようになります。

  1. 第6回 Animator のしくみ メニューを押してから見た目が変わるまでに、何が動いているのか。FX などのレイヤー、ステート、トランジション、パラメーターの役目をまとめました。 2026年11月3日
  2. 第7回 アニメーションを作る ギミックの見た目の変化は、アニメーションクリップに書きます。録画で作る手順、動かせるもの、パスが切れたときの直し方をまとめました。 2026年11月3日
  3. 第8回 メニューでオンオフするギミックを作る 小物をメニューで出したり消したりするギミックを、Animator から自分で組みます。パラメーター、メニュー、アバターへのつなぎ方まで一通り。 2026年11月3日
  4. 第9回 段階で切り替える・少しずつ変えるギミック 服を何着かから選ぶ（Int）、色や大きさを回して変える（Float と Radial Puppet）。Motion Time と Blend Tree の使い方をまとめました。 2026年11月3日
  5. 第10回 ハンドサインで表情を変える GestureLeft・GestureRight の番号で表情を切り替えます。左右の手の優先、まばたきや口との重なり、握りの強さの使い方まで。 2026年11月3日
  6. 第11回 触ると反応するギミック 頭をなでると頬が赤くなる、髪をつかむと表情が変わる。Contact と PhysBone のパラメーターで、触れたことを Animator に伝えます。 2026年11月3日
  7. 第12回 ギミックが動かないとき メニューを押しても動かない、自分にしか見えない、ワールドを移ると戻る。確かめる順番と、よくある原因の一覧です。 2026年11月3日

第4部見た目が思ったとおりにならない

Unity と VRChat での見た目の違いと、半透明の描く順番。

  1. 第13回 Unity と VRChat で見た目が変わる Unity で整えた表情や体の形が、VRChat では元に戻る。その多くは、FX の Animator が BlendShape を書き換えているためです。 2026年11月3日
  2. 第14回 Render Queue（描画の順番） 半透明の髪や服が角度で消える、水面に隠れる。その多くは、描く順番の数字で直せます。 2026年11月2日

これからも回を増やしていきます。
