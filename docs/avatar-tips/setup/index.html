VCC・ALCOM・Unity の入れ方

アバターを改変してアップロードするには、Unity と、プロジェクトを用意するためのツール（VCC か ALCOM）が要ります。それぞれの役目と、どちらを選ぶか、入れる手順を、再現図つきで解説します。

公開 2026年11月3日 · VRChat が使う Unity は 2022.3.22f1 です（2026年11月時点）。

こんなときに読んでください

  • はじめてアバターを改変する。
  • パソコンを買い替えて、改変できるように入れ直す。
  • VCC が重い、Mac で改変したいなど、ALCOM が気になっている。

入れるもの

入れるものは3つです。Unity Hub と Unity は必ず要ります。VCC と ALCOM は、どちらか1つあれば足ります。

Unity Hub
Unity を入れたり、管理したりするソフトです。Unity のアカウントでサインインして、無料のライセンスを有効にするのも、ここで行います。
Unity 2022.3.22f1
アバターを改変するソフトです。VRChat が決めたバージョンを入れます。新しいバージョンを入れても、VRChat にはアップロードできません。
VCC（VRChat Creator Companion）
VRChat 公式のツールです。プロジェクトを作り、VRChat SDK などのパッケージを入れたり更新したりします。
ALCOM
VCC と同じことができる、非公式のツールです。動きが速く、Mac や Linux でも使えます。VCC と設定を共有しているので、両方入れても大丈夫です。
  1. Unity Hubサインインとライセンス
  2. Unity 2022.3.22f1Unity Hub で入れる
  3. VCC か ALCOMプロジェクトを作る
  4. Unity で開くアバターを入れて改変

VCC と ALCOM、どちらを使うか

VCCALCOM
作っているところVRChat（公式）有志（非公式・オープンソース）
使えるパソコンWindows（Mac と Linux は、文字だけで操作する版が一部）Windows・Mac・Linux
速さパッケージを入れるのに待つことがある速い。まとめて入れたり更新したりできる
Unity を入れる画面の案内に沿って、自動で入れられるUnity Hub で自分で入れる（入れたものは自動で見つける）
日本語英語日本語で表示できる

Windows で、はじめてなら VCC がおすすめです。公式なので、配布ページや解説の多くが VCC を前提にしています。Unity も案内どおりに入れられます。

Mac や Linux なら ALCOM を使います。Windows でも、VCC が重いと感じたら ALCOM を試してみてください。プロジェクトやリポジトリの設定は共有されるので、あとから乗り換えても作り直しは要りません。

入れる前に

  • Windows 10 か 11 のパソコン。Unity が動く性能が要ります。
  • 空き容量。Unity だけで数GB、プロジェクトも1つで数GBになります。余裕をもって空けておきます。
  • Unity のアカウント（無料）。Unity Hub を入れたあとにサインインします。持っていなければ、Unity のサイトで作ります。
  • パソコンの名前、ユーザー名、フォルダの名前に、日本語などの全角文字を使わない。Unity でエラーが出ることがあります。プロジェクトの名前も、半角の英数字にします。

VCC で入れる（Windows）

VCC を先に入れて、その案内に沿って Unity Hub と Unity を入れます。

  1. VRChat のダウンロードページ（新しいタブで開きます）から、Creator Companion をダウンロードします。
  2. ダウンロードしたインストーラーを開きます。「Select Setup Install Mode」では「Install for me only (recommended)」を選び、案内に沿って進めます。
  3. VCC を開き、左下の「Settings」を押します。Unity Hub と Unity が入っていないと、「Unity Editors」に印が出ています。「Install Now」を押します。
  4. 「Install Unity」を押すと、Unity Hub を入れる案内が出ます。リンクから Unity のサイトへ行き、Unity Hub をダウンロードして入れます。
  5. Unity Hub が開いたら、Unity のアカウントでサインインします。Unity Hub が Unity を入れるか聞いてきたら、ここでは入れません（VCC が入れます）。
  6. VCC に戻り、「I have installed the Unity Hub」を押します。続けて「Install Unity 2022.3.22f1」を押します。「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」を押します。
  7. 入れ終わったら「Continue」を押します。
  1. Unity Hub と Unity が入っていないときに出ます。押すと、Unity を入れる画面に進みます。
  2. Unity Hub を入れて、サインインしてから押します。
  3. VRChat が使うバージョン（2022.3.22f1）の Unity を、Unity Hub を通して入れます。Android 用の部品もいっしょに入ります。

Unity のライセンスを有効にする

Unity を使うには、Unity Hub でサインインして、ライセンスを有効にしておく必要があります。個人で使うなら、無料の Personal ライセンスで足ります。

Unity を開いたときにライセンスのエラーが出たら、Unity Hub の設定（歯車）の「Licenses」で、ライセンスを追加します。うまくいかないときは、ライセンスの申請ファイルを作って、Unity のサイトで手動で有効にする方法もあります。

ALCOM で入れる（Windows・Mac・Linux）

ALCOM は Unity を自分では入れないので、Unity Hub で入れます。ALCOM は、入れた Unity を自動で見つけます。

  1. ALCOM のサイト（新しいタブで開きます）から、使っているパソコンに合うものをダウンロードします。Windows はインストーラー（.zip）、Mac はディスクイメージ（.dmg）です。
  2. ALCOM を開くと、初期設定が始まります。「UI設定」で言語と見た目を決めて、「進む」を押します。
  3. 「Unity Hubの設定」で Unity Hub が見つからないときは、「unity.comでUnity Hubをダウンロードする」から Unity Hub（新しいタブで開きます） を入れて、サインインします。入れたら「Unity Hubの有無を再確認する」を押します。
  4. 「保存先の設定」でプロジェクトを作る場所を、「バックアップ設定」でバックアップの場所を決めます。どちらも、全角文字の入らない場所にします。
  5. Windows では「システム設定」で、ブラウザの「Add to VCC」などのボタンから ALCOM が開くようにできます。「初期設定が完了しました！」と出たら、「ALCOMを使い始める」を押します。
  6. Unity Hub で Unity 2022.3.22f1 を入れます（次の「Unity Hub で Unity を入れる」）。入れたら、ALCOM を開き直します。
  1. 見つかった Unity Hub の場所が出ます。入っていないときは「見つかりませんでした」と出ます。
  2. Unity のサイトが開きます。Unity Hub をダウンロードして入れ、サインインします。
  3. Unity Hub を入れたら押します。それでも見つからないときは、Unity Hub の場所を手で指定します。
  4. Unity Hub が見つかったら、次の設定に進みます。

Unity Hub で Unity を入れる

ALCOM を使うとき、VCC で Unity をうまく入れられなかったときは、Unity Hub で 2022.3.22f1 を入れます。最新のバージョンではなく、このバージョンを選ぶのが大事です。

  1. Unity Hub を入れて、サインインしておきます。
  2. VRChat の「Current Unity Version」のページ（新しいタブで開きます）を開き、Unity Hub で入れるリンクを押します。Unity Hub が開き、2022.3.22f1 を入れる画面になります。
  3. 入れる部品（モジュール）を選びます。Quest やスマホ向けのアバターも作るなら「Android Build Support」に印を付けます。
  4. 「Install」を押して、入れ終わるのを待ちます。
  5. リンクが開けないときは、Unity Hub の「Installs」→「Install Editor」で、古いバージョンの一覧（Archive）から 2022.3.22f1 を探します。
  1. Quest・Android 向けのアバターを作るときに要ります。中の OpenJDK と Android SDK & NDK Tools にも印を付けます。
  2. iPhone などの iOS 向けを作るときに要ります。
  3. Mac で、Windows（パソコン版）向けのアバターを作るときに要ります。Windows では要りません。
  4. 選んだら押します。入れ終わるまで、しばらくかかります。

Mac で改変するとき

  • VCC の画面つきの版は Windows 用なので、Mac では ALCOM を使います。
  • Unity Hub と Unity は Mac 版を入れます。パソコン版（Windows）向けのアバターを作るには、「Windows Build Support (Mono)」を足します。
  • Mac での改変やアップロードは、VRChat の正式な対応ではありません。うまくいかないときは、Windows のパソコンでの作業も考えてください。

プロジェクトを作る

入れ終わったら、アバター用のプロジェクトを作って、Unity で開いてみます。

VCC のとき

  1. 左の「Projects」で「Create New Project」を押します。
  2. テンプレートの「Avatars」を選びます。
  3. プロジェクトの名前（半角の英数字）と、保存する場所を決めて、「Create Project」を押します。
  4. 一覧に出たプロジェクトの「Open Project」を押すと、Unity で開きます。

ALCOM のとき

  1. 「プロジェクト」で「プロジェクトを作成」を押します。
  2. テンプレートの「VRChat Avatars」を選び、Unity のバージョンが 2022.3.22f1 になっているか確かめます。
  3. 名前（半角の英数字）を入れ、「プロジェクトが作成可能です！」と出たら「作成する」を押します。
  4. 一覧に出たプロジェクトの「Unityを開く」を押すと、Unity で開きます。

はじめて開くときは、時間がかかります。開いたら、上のメニューに「VRChat SDK」があるかを確かめます。アバターや衣装を入れるのは、そのあとです。

ツールやシェーダーを足す

改変でよく使うツールやシェーダーには、VCC や ALCOM で入れるもの（パッケージ）があります。配布ページの「Add to VCC」のボタンを押すと、配布元（リポジトリ）が足されます。ALCOM でも同じボタンから足せます。

ボタンが無いときは、配布ページにある URL を、VCC なら「Settings」→「Packages」→「Add Repository」、ALCOM なら「VPMリポジトリを追加」に入れます。

足したら、プロジェクトの「Manage Project」（ALCOM は「管理」）を開き、使いたいパッケージを入れます。

よくある困りごと

Unity Hub が新しいバージョンを勧めてくる

起きること
Unity Hub が、新しいバージョンを入れるように勧めてくる。古いバージョンだとセキュリティの警告が出る。
直し方
入れずに閉じます。VRChat 用のプロジェクトは 2022.3.22f1 のままにします。VRChat も、この警告は VRChat のアバターやワールドには当てはまらないと案内しています。

Unity が見つからないと出る

起きること
VCC や ALCOM で、Unity が見つからないと出る。プロジェクトが開けない。
直し方
Unity Hub で 2022.3.22f1 が入っているかを確かめます。入っていれば、VCC は「Settings」の Unity Editors で、ALCOM は「設定」の「Unityを追加」で、Unity の場所を指定します。ALCOM は開き直すと見つかることもあります。

ライセンスのエラーで Unity が開かない

起きること
Unity を開こうとすると、ライセンスがないと出る。
直し方
Unity Hub でサインインしているかを確かめ、「Licenses」で無料のライセンスを追加します。

Unity Hub が入らない

起きること
Unity Hub や Unity を入れる途中で止まる、失敗する。
直し方
許可を求められたら「はい」を押します。それでもだめなら、インストーラーを右クリックして「管理者として実行」で開きます。

プロジェクトでエラーが出る

起きること
プロジェクトを作ったり開いたりすると、エラーがたくさん出る。
直し方
プロジェクトの名前や、保存した場所のフォルダ名に全角文字が無いかを確かめます。パソコンの名前やユーザー名が日本語のときも起きることがあります（ALCOM では「PC名に問題あり」と出ます）。

VCC が重い・パッケージが入らない

起きること
VCC の起動や、パッケージを入れるのに時間がかかる。
直し方
ALCOM を試してみてください。設定を共有しているので、同じプロジェクトをそのまま開けます。

気をつけること

  • Unity は 2022.3.22f1 から上げないでください。VRChat は 2026年6月から Unity 6 版の公開テストをしていますが、Unity 6 で作ったものは、まだアップロードできません。VRChat がバージョンを変えるときは、公式のお知らせに従います。
  • VCC、ALCOM、Unity Hub は、それぞれの公式の配布ページから入れます。
  • ALCOM は VRChat の公式のツールではありません。ALCOM で困ったことは、VRChat ではなく ALCOM の配布元に問い合わせます。
  • 改変の前に、プロジェクトのバックアップを取っておくと安心です。VCC も ALCOM も、プロジェクトのバックアップを作れます。

まとめ

  • Unity Hub と Unity 2022.3.22f1 は必ず入れます。新しいバージョンは入れません。
  • Windows ではじめてなら VCC、Mac や Linux、VCC が重いときは ALCOM を使います。
  • パソコンの名前、フォルダ、プロジェクトの名前には全角文字を使いません。
  • プロジェクトを作って Unity で開き、「VRChat SDK」のメニューがあれば準備完了です。
