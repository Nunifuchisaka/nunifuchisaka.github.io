制作物一覧

これまでに作ったシェーダー・アバターギミック・ツール11点です。対応している環境を見てから、説明書を読んだり BOOTH で手に入れたりできます。

種類で絞り込む

  • シェーダー

    DeepFrostIce

    VRChat PCアバター用の氷シェーダー。屈折・フロスト・凍結と融解まで表現。

    対応
    VRChat PCアバター（Quest 非対応）
    必要なもの
    VRChat Avatar SDK を入れた Unity プロジェクト（Built-in RP・Forward）
    価格
    β版・先行販売中

    説明書を読む: DeepFrostIce BOOTH で見る: DeepFrostIce （新しいタブで開きます）

  • テクスチャ

    GlossySkin

    凪 -Nagi- 専用のツヤ肌マスク。lilToonのMatCapのマスクを差し替えるだけ。

    対応
    凪 -Nagi-（VRChat PCアバター）
    必要なもの
    lilToon（凪に付属）。おまけのスライダーには Modular Avatar も

    説明書を読む: GlossySkin BOOTH で見る: GlossySkin （新しいタブで開きます）

  • アバターギミック

    HeartBeat

    相手の頭が胸に触れたときだけ、すぐそばで心音が鳴る。

    対応
    VRChat アバター（Chest ボーンがあるもの）
    必要なもの
    Modular Avatar

    説明書を読む: HeartBeat

  • アバターギミック

    SpiderWeb

    指先から糸が伸び、腕を振ると糸と薔薇の花びらが降る。

    対応
    VRChat PCアバター（Quest 非対応）
    必要なもの
    VRChat SDK3（Avatars）、Modular Avatar 1.15 以降

    説明書を読む: SpiderWeb BOOTH のショップへ: SpiderWeb （新しいタブで開きます）

  • アバターギミック

    餓者髑髏 -Gashadokuro-

    背後の地面から4倍の大きさの骸骨が燃えながら迫り上がり、自分の動きに合わせて動く。

    対応
    VRChat PCアバター（Quest 非対応）
    必要なもの
    Modular Avatar、lilToon 2.3 以降、Final IK か Final IK Stub

    説明書を読む: 餓者髑髏 -Gashadokuro- BOOTH で見る: 餓者髑髏 -Gashadokuro- （新しいタブで開きます）

  • アバターギミック（アクセサリー）

    Regret

    腕や足に付けた骨を振ると飛んでいき、床に残る。元の場所で触れると、また付く。

    対応
    VRChat PCアバター（Quest 非対応）
    必要なもの
    Modular Avatar、lilToon

    説明書を読む: Regret BOOTH で見る: Regret （新しいタブで開きます）

  • Blenderアドオン

    NuniAvatarToolkit

    隠れメッシュの削除や服のフィットなど、アバター制作のメッシュ最適化をひとまとめに。無料。

    対応
    Blender 4.2 以降
    価格
    無料
    最新版
    1.0.0

    説明書を読む: NuniAvatarToolkit BOOTH で見る: NuniAvatarToolkit （新しいタブで開きます）

  • Windowsツール

    PublicWalker

    前に行ったVRChatのpublicインスタンスに戻ってきたら知らせてくれる常駐ツール。

    対応
    Windows（VRChat は Steam 版）
    必要なもの
    WebView2（Windows 11 と更新済みの Windows 10 には入っています）。XSOverlay は任意
    最新版
    1.1.0

    説明書を読む: PublicWalker BOOTH で見る: PublicWalker （新しいタブで開きます）

  • Windowsアプリ（β版）

    DeskCinema

    ローカル動画やYouTubeを、モニターごとに動画壁紙として再生。

    対応
    Windows
    最新版
    0.2.1

    説明書を読む: DeskCinema BOOTH で見る: DeskCinema （新しいタブで開きます）

  • オーバーレイアプリ（β版）

    KeyDisplay

    押しているキーやマウスの操作を画面に出すオーバーレイ。Unity・Blenderの解説動画向け。

    対応
    Windows・macOS（表示はメインのモニターだけ）

    説明書を読む: KeyDisplay BOOTH のショップへ: KeyDisplay （新しいタブで開きます）

  • Windowsツール

    ImageGetter

    複数のURLから、シェア画像（og:image）をまとめて取得・保存。

    対応
    Windows（exe 版は Python 不要）

    説明書を読む: ImageGetter BOOTH で見る: ImageGetter （新しいタブで開きます）
