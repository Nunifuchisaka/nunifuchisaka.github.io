ソフトとツール

アバターを改変してアップロードするまでに使う、ソフトやツールの名前です。

VCC（VRChat Creator Companion）

VRChat 公式の、プロジェクトを作ってツールやシェーダーを入れるアプリ（Windows 用）。

VCC でプロジェクトを作ると、VRChat SDK が入った Unity のプロジェクトができます。Modular Avatar などのツールも、配っている人のリポジトリを VCC に足してから、プロジェクトに入れます。Mac や Linux では使えないので、ALCOM を使います。

ALCOM

VCC と同じことができる、有志が作ったアプリ。Windows・Mac・Linux で使える。

プロジェクトを作る、ツールやシェーダーを入れる、といった VCC と同じ使い方ができます。VCC と違い、Mac や Linux でも使えます。

Unity Hub

Unity を入れたり、プロジェクトを開いたりする、Unity 公式のアプリ。

VRChat は決まったバージョンの Unity（2026年11月時点で 2022.3.22f1）を使います。そのバージョンを Unity Hub で入れておき、新しいバージョンには上げません。

VRChat SDK

Unity に入れて使う、VRChat 公式のアバター作りとアップロードの道具。

VRChat SDK が入ったプロジェクトでは、Unity の上のメニューに「VRChat SDK」が出て、Builder でアップロードしたり、Content Manager でアップロードしたアバターを見たりできます。VCC か ALCOM でプロジェクトを作ると、はじめから入っています。

VRChat SDK に入っている、アバターを作るためのしくみの名前です。いま VRChat でアップロードするアバターは、すべてこのしくみで動きます。

Built-in Render Pipeline

Unity の描き方のしくみの1つ。VRChat のアバターは、これで描かれる。

Unity には描き方のしくみ（Render Pipeline）がいくつかあり、VRChat は Built-in Render Pipeline を使います。URP や HDRP 向けに作られたシェーダーは、VRChat のアバターでは使えません。

Modular Avatar（MA）

衣装やギミックを、元のデータを書き換えずにアバターへ組み込むツール。

衣装やギミックに MA のコンポーネントを付けておくと、再生やアップロードのときに、その指示どおりに自動で組み込みます。元のアバターのファイルは書き換えないので、外したいときは消すだけで戻ります。

AAO（Avatar Optimizer）

見た目を変えずに、アップロードのときに自動でアバターを軽くするツール。

アバターの一番上に AAO Trace And Optimize を付けると、使っていない部品を消したり、メッシュをまとめたりして、パフォーマンスランクを上げやすくします。元のデータは書き換えません。

Hierarchy や Project で何かを選ぶと、その設定がここに出ます。付いているコンポーネントの追加や設定も、ここで行います。

Scene ビューでは、置いた物を見ながら動かせます。プロジェクトの中に、シーンのファイルをいくつも作れます。

Is Active

オブジェクトを出すか消すかの設定。Inspector の名前の左のチェック。

チェックを外すと、オブジェクトは見えなくなり、付いているコンポーネントも動きません。アニメーションクリップでオンオフするときは、この値を 1（出す）と 0（消す）で書きます。

アバターの体と見た目

アバターの形・骨・色を作っている部品です。

VRC Avatar Descriptor

アバターの一番上に付ける、VRChat のアバターの設定をまとめたコンポーネント。

視点の位置、話したときの口の動き、Playable Layers に入れるコントローラー、Expressions Menu と Expression Parameters を、ここで決めます。これが付いている物が、1体のアバターとして扱われます。

関係する言葉 Playable Layers、Expressions Menu（Action Menu）、Expression Parameters

Humanoid

人型の骨の決まった並び。VRChat は、これを使って体の動きをアバターに当てはめる。

腕・脚・頭・指などの骨は Humanoid として扱われ、VRChat が動かします。そのため、FX のアニメーションクリップでは、これらの骨は動かせません。

関係する言葉 Armature、ボーン、FX

Armature

アバターの骨（ボーン）をまとめたオブジェクト。Hips から下に、骨が親子で並ぶ。

衣装にも、同じ名前の骨が並んだ Armature があります。Modular Avatar の Merge Armature は、衣装の骨をアバターの骨にまとめて、服が体に沿って動くようにします。

くわしく 第3回 衣装を着せる

関係する言葉 ボーン、MA Merge Armature、Humanoid

ボーン

メッシュを動かすための骨。骨が動くと、それに結び付いたメッシュが曲がる。

Armature の中に、親子の形で並んでいます。髪やスカートの骨は、PhysBone で揺らします。ボーンの数は、パフォーマンスランクの項目にもなっています。

くわしく 第3回 衣装を着せる、第4回 パフォーマンスランクと軽量化

関係する言葉 Armature、PhysBone、Skinned Mesh Renderer

メッシュ

三角形（ポリゴン）を組み合わせて作った、物の形のデータ。

体、髪、服などは、それぞれメッシュでできています。メッシュの数と三角形の数が多いほど、描くのが重くなります。

くわしく 第4回 パフォーマンスランクと軽量化

関係する言葉 ポリゴン、Skinned Mesh Renderer、マテリアル

Skinned Mesh Renderer

ボーンに合わせて曲がるメッシュを描くコンポーネント。体や服に付いている。

使うメッシュとマテリアル、BlendShape の値が、ここに並びます。表情や体型の調整をするときは、このコンポーネントの BlendShapes を開きます。

関係する言葉 メッシュ、BlendShape（シェイプキー）、マテリアル

BlendShape（シェイプキー）

メッシュの形を少しずつ変える設定。表情や、体型の調整に使う。値は 0〜100。

笑顔、まばたき、口の形、胸の大きさなど、アバターごとに用意されています。アニメーションクリップで値を書くと、ハンドサインやメニューで表情を変えられます。

関係する言葉 Skinned Mesh Renderer、アニメーションクリップ（クリップ）、ハンドサイン（GestureLeft・GestureRight）

マテリアル

色や質感の設定。どのシェーダーで、どのテクスチャを使うかを決める。

1つのメッシュに、いくつものマテリアルを使えます。マテリアルの数が多いほど描くのが重くなるので、パフォーマンスランクの項目にもなっています。

くわしく 第4回 パフォーマンスランクと軽量化、第14回 Render Queue（描画の順番）

関係する言葉 シェーダー、テクスチャ、Render Queue

シェーダー

光の当たり方や色の出し方を計算するプログラム。lilToon など。

マテリアルごとに、どのシェーダーを使うかを選びます。アバターが使うシェーダーがプロジェクトに入っていないと、ピンク一色で表示されます。Quest やスマホでは、VRChat/Mobile のシェーダーしか使えません。

くわしく 第2回 アップロードのしかた、第5回 Quest・スマホ対応

関係する言葉 マテリアル、lilToon、Quest・Android・iOS

テクスチャ

メッシュに貼る画像。肌や服の模様、色などを描いている。

マテリアルが、どのテクスチャをどう使うかを決めます。大きな画像が多いと、テクスチャのメモリが増えて、パフォーマンスランクが下がります。

くわしく 第4回 パフォーマンスランクと軽量化

関係する言葉 マテリアル、アトラス化

ポリゴン

メッシュを作っている三角形。数が多いほど細かいが、重くなる。

パフォーマンスランクでは、三角形の数（Triangles）で数えます。使わない服や小物を消すと減ります。

くわしく 第4回 パフォーマンスランクと軽量化

関係する言葉 メッシュ、パフォーマンスランク

PhysBone

髪やしっぽ、スカートを揺らす VRChat のコンポーネント。つかんで動かすこともできる。

骨に付けると、体の動きに合わせて揺れます。つかまれたか、どれだけ曲がったかをパラメーターで受け取れるので、ギミックにも使えます。数が多いと重くなり、パフォーマンスランクの項目にもなっています。

くわしく 第11回 触ると反応するギミック、第4回 パフォーマンスランクと軽量化

関係する言葉 ボーン、Contact（Sender と Receiver）

Bounds

メッシュがすっぽり入る、見えない箱。描く順番や、パフォーマンスランクの計算に使われる。

半透明の物を描く順番は、カメラからこの箱の中心までの距離で決まります。箱が大きすぎると、パフォーマンスランクの「大きさ」の項目が悪くなります。

Animator とアニメーション

ギミックを自分で組むときに使う、Animator まわりの言葉です。

ギミック

メニューやハンドサインで、アバターの見た目や動きを切り替えるしかけ。

小物を出し入れする、表情を変える、色や大きさを変える、触れると反応する、などがあります。Animator・パラメーター・メニューを組み合わせて作ります。

関係する言葉 Animator、パラメーター、Expressions Menu（Action Menu）

Animator

パラメーターを見て、いまどのアニメーションを再生するかを決めるしくみ。

アバターの一番上に付いている Animator コンポーネントが、コントローラーの中身にしたがって動きます。Unity の Animator ウィンドウでは、レイヤー・ステート・トランジションを組み立てます。

関係する言葉 Animator Controller（コントローラー）、レイヤー、ステート

Animator Controller（コントローラー）

Animator の中身（レイヤー・ステート・トランジション・パラメーター）を入れたファイル。拡張子は .controller。

Project で右クリックして作ります。VRChat では、Playable Layers の枠（FX など）に入れて使います。自分で作ったものは、Modular Avatar の Merge Animator でアバターに足せます。

関係する言葉 Animator、Playable Layers、MA Merge Animator

Playable Layers

VRChat がアバターに用意している、コントローラーを入れる枠。FX・Gesture・Action などがある。

VRC Avatar Descriptor で、枠ごとにコントローラーを入れます。見た目を変えるギミックは FX に入れます。コントローラーの中の「レイヤー」とは別のものです。

くわしく 第6回 Animator のしくみ

関係する言葉 FX、VRC Avatar Descriptor、レイヤー

FX

Playable Layers の1つ。オンオフ・表情・色など、見た目を変えるギミックを入れる枠。

ほとんどのギミックは FX で作ります。Humanoid の骨（腕や脚など）は、FX では動きません。

くわしく 第6回 Animator のしくみ、第7回 アニメーションを作る

関係する言葉 Playable Layers、Humanoid

レイヤー

コントローラーの中の段。ギミック1つにつき1つ作ることが多い。

レイヤーは上から順に動き、同じものを動かすときは、下のレイヤーが勝ちます。足したレイヤーは Weight を 1 にしないと効きません。

くわしく 第6回 Animator のしくみ、第10回 ハンドサインで表情を変える

関係する言葉 Weight（レイヤーの重み）、ステート、Animator Controller（コントローラー）

Weight（レイヤーの重み）

レイヤーをどれだけ効かせるか（0〜1）。足したレイヤーは 0 なので、1 にする。

レイヤーの右の歯車から変えます。0 のままだと、そのレイヤーは何も書かないので、ギミックが動きません。

関係する言葉 レイヤー

ステート

「帽子が出ている」のような、いまの状態を表す箱。1つのステートに、1つのクリップを入れる。

Animator ウィンドウでは長方形で表示されます。オレンジ色のステートは、そのレイヤーで最初に入るステート（Layer Default State）です。

くわしく 第6回 Animator のしくみ、第8回 メニューでオンオフするギミックを作る

関係する言葉 トランジション、アニメーションクリップ（クリップ）、Any State

Any State

「いまどのステートにいても」を表す箱。ここからの矢印は、条件を満たせばどこからでも移る。

ステートが多いときに便利です。条件を満たしている間、同じステートに入り直し続けることがあるので、Can Transition To Self の設定に気をつけます。

くわしく 第6回 Animator のしくみ、第9回 段階で切り替える・少しずつ変えるギミック

関係する言葉 ステート、トランジション

トランジション

ステートからステートへの矢印。条件（Conditions）を満たすと、矢印の先へ移る。

ステートを右クリックして「Make Transition」で引きます。オンオフのギミックでは、Has Exit Time を外し、Transition Duration を 0 にすることが多いです。
