FEATURES

思い出の場面を、いつでも目の前に。

ライブラリから選ぶだけで、デスクトップの背後に動画を表示します。アイコンや右クリックなど、普段のデスクトップ操作を妨げません。

ローカル動画を壁紙に

MP4、WebM、MOVなどの動画をライブラリへ登録。選んだ動画を、デスクトップの背景としてループ再生できます。

YouTubeにも対応

通常動画やShortsのURLを登録できます。ライブラリに映像を増やす感覚で、好きなシーンをすぐ選べます。

モニターごとに別のシーン

接続中のディスプレイを自動検出。モニター単位で、動画・壁紙化・音声・音量をそれぞれ設定できます。

必要なときだけ、音を

音声はモニターごとに初期状態ミュート。オンにした画面だけ再生でき、音量も個別に調整できます。

作業に合わせて止められる

ゲームや動画を全画面表示しているあいだは一時停止する設定に対応。集中したい時間にもなじみます。

ループもランダムも

同じ動画を繰り返すか、再生終了時に別の動画へ切り替えるかを、ディスプレイごとに選択できます。

縦向きディスプレイにも対応

画面の向きをアプリから切り替えられます。縦型モニターにも、映像を合わせて表示できます。

7つのカラーテーマ

ダークから、桜・海辺・森の朝・夢夜まで。気分やデスクトップに合わせて配色テーマを選べます。

日本語と英語に対応

アプリの表示言語は日本語と英語から選べます。好みや利用環境に合わせて切り替えられます。

AIエージェントからも操作

Agent APIと専用Skillを用意。AIエージェントやローカルスクリプトから、ライブラリや壁紙設定を操作できます。

GET STARTED

はじめるまで、3ステップ。

インストールしたら、映像を選んで、画面に割り当てるだけです。

DeskCinemaをインストール

BOOTHからダウンロードしたセットアップファイルを実行します。Windowsの案内に沿ってインストールを完了してください。

動画ライブラリを作る

動画を追加からローカルの動画を選択するか、YouTubeを追加からURLを登録します。フォルダ分けも可能です。

ディスプレイでシーンを選ぶ

各ディスプレイの動画をクリックして選択。動画壁紙をオンにすると、すぐデスクトップの背景へ表示されます。

CONTROLS

画面ごとに、ちょうどいい設定を。

使う場面に合わせて、動画・音声・再生の振る舞いを個別に整えられます。

NOTES

ご利用にあたって

YouTube動画について

埋め込み再生が許可されていない動画、年齢制限または地域制限のある動画は再生できません。

β版について

DeskCinemaはβ版です。環境によっては挙動が変わる場合があります。大切な作業中は、まず短時間の利用で動作をご確認ください。
