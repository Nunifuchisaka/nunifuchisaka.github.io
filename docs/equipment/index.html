VR機材

VRChatで使っている機材17点を、用途ごとにまとめました。

  • ゴーグルとつけ心地6
  • 電源とつなぎ方4
  • 眠る・くつろぐ2
  • お手入れ3
  • フルトラ機材2

ゴーグルとつけ心地

  • Meta Quest 3 VRゴーグル（HMD）。単体でも、PCにつないでも使える。 Amazonで見る（新しいタブで開きます）
  • BOBOVR M3 Pro バッテリー付きのヘッドストラップ。後ろの重さで前後のバランスがとれ、遊べる時間ものびる。 Amazonで見る（新しいタブで開きます）
  • 視力補正レンズ ゴーグルの内側に取り付けて、眼鏡なしでくっきり見るためのレンズ。 shop.roox.jpで見る（新しいタブで開きます）
  • フェイスクッション（アイスシルク） 顔に当たる部分のクッション。光漏れを減らす。 Amazonで見る（新しいタブで開きます）
  • コントローラー グリップ コントローラーを握りやすくし、手から落ちにくくする。 Amazonで見る（新しいタブで開きます）
  • 釣具の板おもり 少しずつ切って貼れるおもり。ゴーグルの前後の重さの釣り合い（カウンターウエイト）の微調整に。 Amazonで見る（新しいタブで開きます）

電源とつなぎ方

  • TP-Link Wi-Fi 中継器 PCとゴーグルを無線でつなぐ（無線VR）ときの通信を安定させる。 Amazonで見る（新しいタブで開きます）
  • KIWI design リンクケーブル PCとゴーグルを有線でつなぐ（有線VR）ためのケーブル。 Amazonで見る（新しいタブで開きます）
  • UGREEN Linkケーブル Linkケーブル。 ぬにふちさかは、コンセントからの給電のためだけに使っています。 Amazonで見る（新しいタブで開きます）
  • 単3 リチウムイオン充電池 2550mWh 繰り返し使える単3形の充電池。 Amazonで見る（新しいタブで開きます）

眠る・くつろぐ

  • VR睡眠用まくら・ケーブルの吊り下げワイヤ ゴーグルを着けたまま横になれるまくらと、ケーブルを天井から吊るして体に絡まないようにするランニングワイヤ。 shop.roox.jpで見る（新しいタブで開きます）
  • アイマスク（4枚入り） 光をさえぎるアイマスク。 Amazonで見る（新しいタブで開きます）

お手入れ

  • レンズ用ブロアー レンズのほこりを、触らずに吹き飛ばす。 Amazonで見る（新しいタブで開きます）
  • 電動エアダスター 機材のすき間のほこりを強い風で飛ばす。 Amazonで見る（新しいタブで開きます）
  • エレクトロニッククリーナー コントローラーのスティックの洗浄に。 Amazonで見る（新しいタブで開きます）

フルトラ機材

  • HaritoraX 2 体に着けて全身の動きをアバターに反映するトラッカー。内蔵バッテリー式。 ja.shiftall.netで見る（新しいタブで開きます）
  • Uni-motion 全身の動きを取るトラッカー。単3電池式。 uni-motion.comで見る（新しいタブで開きます）
