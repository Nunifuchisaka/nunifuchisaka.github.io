Claude Code の使い方

VRChat用のアセット（シェーダーやアバターのギミック）とその説明書サイト、そしてこのサイトを、AnthropicのClaude Codeと一緒に作っています。エージェントの構成と、それぞれの作り方を紹介します。

構成

ぬにふちさか

やりたいことを日本語で伝え、出てきた選択肢から選ぶ

Claude Code

依頼を読み、作業を分けて任せ、結果を報告する

エージェント

  • 意匠家 デザイン

    コードより先に方向性の案を出す。サイトなら配色・書体・ワイヤーフレーム、アセットなら見た目の方向性。

  • 技師 実装

    コードを書いて確かめる。サイトのHTMLやCSSも、シェーダーやUnityのエディター拡張、ギミックの構成も。

スキル

  • Frontend Design

    テンプレート感のないデザインのための、Anthropic公式のスキル。2026年10月31日に導入。

  • booth-product-site

    BOOTHの商品の説明書サイトを作るための、自分用のスキル。

プロジェクトの覚え書き

  • CLAUDE.md

    リポジトリに置いている指示書。サイトの構成・ビルドの手順・クラス名の付け方を書き、「常に日本語で応答する」と決めている。

サイトを作る流れ

  1. ぬにふちさか

    依頼する

    やりたいことを日本語で伝える。

  2. 意匠家

    案を見る

    コードを書く前に、配色・書体・ワイヤーフレームなどの方向性の案を出してもらう。

  3. ぬにふちさか

    選んで承認する

    確認はいつも選択式。おすすめが先頭に来る。

  4. 技師

    作って確かめる

    ビルド・HTMLの検証・ライトとダーク、PCとスマホのスクリーンショットで確かめる。

  5. ぬにふちさか

    報告を読む

    確認できなかったことも、はっきり書いてもらう。

VRChat用アセットを作る流れ

DeepFrostIceのようなシェーダーや、アバターのギミックも、同じ体制で作っています。

  1. ぬにふちさか

    依頼する

    作りたいシェーダーやギミックを日本語で伝える。

  2. 意匠家

    方向を決める

    見た目の方向性の案を出してもらい、選択式で選ぶ。

  3. 技師

    作る

    シェーダー、導入を助けるUnityのエディター拡張（Fit To AvatarやRefitのボタンなど）、Modular Avatar用のギミックの構成を作る。

  4. Claude Code → ぬにふちさか

    確かめる

    Claude Codeがコンパイルやテスト、スクリーンショットで確かめ、最後にぬにふちさかがUnityとVRChatで実際に試す。

  5. Claude Code

    説明書を書く

    説明書サイト（日本語と英語）とBOOTHの商品ページを書く。ポリゴン数などは実測値に合わせて直す。

決めているルール

  • 確認や承認は選択式にする。
  • 確認できなかったことは明記する。
  • force push はしない。
