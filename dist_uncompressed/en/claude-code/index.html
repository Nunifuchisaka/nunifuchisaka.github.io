How I use Claude Code

This site and my BOOTH manual sites are built together with Anthropic's Claude Code. Here is how my agents are set up and how a request moves from idea to release.

Setup

Me

Asks for things in plain Japanese and picks from the options offered

Claude Code

Reads the request, splits the work and reports back

Agents

  • 意匠家 (Ishōka) Design

    Proposes the direction before any code: palette, type, wireframes, and the one element that makes the page memorable.

  • 技師 (Gishi) Implementation

    Writes the code, builds it, and checks it with validators and screenshots.

Skills

  • Frontend Design

    Anthropic's official skill for design that doesn't look templated. Added on October 31, 2026.

  • booth-product-site

    A skill of my own for making the manual sites for my BOOTH products.

Project notes

  • CLAUDE.md

    Kept in the repository: how the site is structured, the build commands, and the class naming rules. It also says to always reply in Japanese.

How a request moves

  1. Ask

    Say what I want in Japanese.

  2. See the proposal

    Before any code, Claude shows a design direction: colors, type and wireframes.

  3. Pick and approve

    Confirmations always come as choices, with the recommended one first.

  4. Build and check

    Build, validate the HTML, and look at screenshots in light and dark, desktop and phone.

  5. Read the report

    The report says plainly what could not be checked.

Rules I keep

  • Confirmations and approvals are multiple choice.
  • Anything that couldn't be verified is written down as such.
  • No force pushes.
