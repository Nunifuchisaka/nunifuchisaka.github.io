Avatar Tips #12

When a gimmick doesn't work

You press it in the menu and nothing happens. Only you can see it. It resets when you change worlds. When a gimmick doesn't work the way you expected, this page shows where to start, what order to check things in, and a list of common causes. When you're stuck, come here first.

Published November 3, 2026 · This covers Unity's Built-in Render Pipeline and VRChat avatars (Avatars 3.0). Up to date as of November 2026.

Read this when

  • A gimmick you built doesn't do anything when you press it in the menu.
  • You can see it, but someone told you they can't.
  • Your toggles reset when you change worlds or switch avatars.
  • It worked in Unity, but it doesn't work in VRChat.
  • You can't tell what's wrong, and you don't know where to start looking.

The order to check things

A gimmick works by passing a value along in this order: menu → parameter → state → clip → what you see (for details, see #6 How the Animator works). If it stops being passed along somewhere, nothing after that point works.

So start at the front and check, one step at a time, how far the value gets. The cause is just before the point where it stops. This finds the problem much faster than fixing whatever comes to mind.

And check in Unity first. To test in VRChat, you have to upload and wait every time. In Unity, you just fix it and press Play, and you can check right away.

  1. 1. Play in UnityPress the menu in Gesture Manager
  2. 2. ParameterDoes the value change?
  3. 3. StateDoes it go into a different state?
  4. 4. ClipIs it writing the right things?
  5. 5. Yourself in VRChatUpload and try it
  6. 6. With friendsCan other people see it?

What to look at in each step, and where to look when it stops

1. Play in Unity with Gesture Manager
Follow the steps in the next section: press Unity's Play button, then press the gimmick's item in the Gesture Manager menu. If it works in Unity, your Animator and clips are set up correctly. Go on to 5. If it doesn't work in Unity either, check from 2 in order.
2. Does the parameter's value change?
When you press the menu, look at the Debug section of Gesture Manager and see whether that parameter's value changes. If it doesn't change, the cause is the menu or Expression Parameters. Check that the names match, and that the parameter is in Expression Parameters.
3. Does it go into a different state?
If the parameter changes but the state doesn't, the cause is the parameter name in the Animator, or the transition conditions. In the Animator window, look at which state is running in that layer (how to look is in the next section).
4. Is the clip writing the right things?
If the state changes but what you see doesn't, the cause is what's in the clip, or the layer settings. Check that the clip's paths aren't broken (Missing), that the layer's Weight isn't 0, and that a lower layer isn't writing the same thing.
5. Check it yourself in VRChat
Once it works in Unity, upload and try it in VRChat. If it works in Unity but not in VRChat, look at things that were removed during upload (such as EditorOnly objects), and at which avatar you uploaded to.
6. Ask a friend how it looks to other people
Once it works for you, ask a friend to look. Gesture Manager and your own screen can only show you how you see yourself. If other people can't see it, check the parameter's Synced setting (sends it to other people) and the Quest version.

Once you know which step it stops at, pick that problem in the "Common causes" list below to narrow down where to look.

Tools for checking

There are three main tools for checking: Gesture Manager in Unity, the Animator window in Unity, and the displays inside VRChat.

Gesture Manager (run it like VRChat, in Unity)

Gesture Manager is a tool that runs your avatar's Animator in Unity Play mode the same way VRChat does. You can try out your menu (Expressions Menu) and hand gestures inside Unity. It's made by BlackStartx (Gesture Manager download page (opens in a new tab)).

Add Gesture Manager to your project from the project list in VCC or ALCOM. For how to add it, see #1 Installing VCC, ALCOM and Unity.

  1. In Unity's top menu, choose Tools → Gesture Manager Emulator. An object called GestureManager is added to the scene. It's only for testing, and it isn't included in your upload.
  2. Press the Play button (▶) at the top center of Unity. Unity goes into Play mode, and the Animator starts running.
  3. Select GestureManager in the Hierarchy. A round menu, the same shape as VRChat's, appears in the Inspector. If there are two or more avatars, choose the one you want to test.
  4. In the round menu, press the item for the gimmick you want to test. Check in the Scene or Game view whether it changes.
  5. Open the Debug section near the top of the Inspector. It lists parameter values, layer Weights, and the state each layer is in right now. Press the menu and see which values change.
  6. When you're done checking, press the Play button again to stop. Settings you change while playing go back when you stop. Make your fixes after you stop.
  1. Turning the hat on in the menu set Hat to true. The menu and Expression Parameters are fine.
  2. The Hat layer's Weight is 0. With this, what you see won't change even when the state changes. Set the Weight to 1.
  3. The state is Hat_On. The transition is fine too.

Names and layout in Gesture Manager can differ between versions. If you can't find a section, try pressing the buttons in the Inspector one by one.

The Animator window (see which state is running)

  1. While playing with Gesture Manager, select your avatar in the Hierarchy (the top object, with the VRC Avatar Descriptor on it).
  2. Open the Animator window with Window → Animation → Animator. Sometimes you can also open the layer you want (FX, for example) from Gesture Manager's Debug section.
  3. In the Layers tab on the left, choose the layer you want to look at.
  4. The state it's in right now shows a blue progress bar underneath that moves. Press the menu and see whether the bar moves to another state. If it doesn't, the transition conditions or the parameter name are wrong.
  5. Select a transition arrow, and its conditions (Conditions) appear in the Inspector. Check that the parameter name and value match.

Settings you change in the Animator window while playing may also go back when you stop. Once you know what to change to fix it, stop playing and make the same change again.

Displays inside VRChat

Inside VRChat, there's also a display that shows your avatar's parameter values. In the Expressions menu (Action Menu), around the settings (Options), there's an item that turns on a debug display (Debug). Its name and location can change with VRChat updates, so if you can't find it, check VRChat's official documentation for where it is now.

The VRChat SDK Builder also has a way to test only in VRChat on your own PC, without uploading (Build & Test). It's faster than uploading every time.

Only other people can check how you look to other people. When you check sync (Synced) or the Quest version, ask a friend to look at you in the same world. If you have friends on Quest or mobile, ask them to look too, so you can be sure.

Common problems and how to fix them

Nothing happens when you press the menu, even in Unity

What happens
When you press the menu in Gesture Manager, the parameter and the state both change. But what you see doesn't.
Cause
Most often, a layer you added still has a Weight of 0. When you add a layer in Unity, it's created with a Weight of 0.
Fix
In Layers in the Animator window, click the gear on that layer and set Weight to 1. If it still doesn't change, check the clip's paths and the lower layers.

Only you can see it

What happens
On your screen, the hat is showing. Your friends say there's no hat.
Cause
Synced is unchecked for that parameter in Expression Parameters. The value isn't being sent to other people.
Fix
Check Synced and upload again. If your friends are on Quest or mobile, also check that the Android version includes the gimmick.

It turns off when you change worlds

What happens
You turn the hat on, but when you change worlds, the hat is gone.
Cause
Saved is unchecked for that parameter in Expression Parameters. When you change worlds, it goes back to the Default value.
Fix
Check Saved and upload again.

It flickers when you turn it on

What happens
When you turn it on, the hat keeps rapidly appearing and disappearing.
Cause
A transition from Any State has Can Transition To Self checked. While the condition is true, it keeps re-entering the same state.
Fix
Select the arrow from Any State and uncheck Can Transition To Self.

It works in Unity, but doesn't show up in VRChat

What happens
The hat shows up in Gesture Manager. But after you upload and press it in VRChat, it doesn't.
Cause
The hat object's tag is EditorOnly, so it's removed during upload. You may also have uploaded to a different avatar.
Fix
Set Tag to Untagged and upload again. Also check which avatar you're uploading to in the Builder.

Too many parameters to upload

What happens
After you add a gimmick, the Builder warns that there are too many parameters, and you can't upload.
Cause
The total of your synced parameters is over 256 bits. Parameters added by outfits and tools count too.
Fix
Delete parameters you don't use, or uncheck Synced on ones other people don't need to see. Several on/off toggles, like outfit switches, can be combined into one Int (8 bits).

Things to watch out for

  • Fix only one thing at a time. If you change several things at once, you won't know which one fixed it, or which one broke it.
  • Before you fix anything, make sure you can undo it. Duplicate the controller and clips, or export the avatar's folder.
  • Settings you change while Unity is playing go back when you stop. Make your fixes after you stop playing.
  • Even if it works in Gesture Manager, you can't check how it looks to other people (sync) there. In the end, ask a friend to look in VRChat.
  • If you add things directly to a purchased avatar's FX or menu, they can be lost when the avatar is updated. For things you make yourself, connecting them with MA is safer.
  • VRChat's debug display and Gesture Manager's screens can change names or locations with updates.

Summary

  • A gimmick works in this order: menu → parameter → state → clip → what you see. Start at the front and check how far the value gets.
  • Check with Gesture Manager in Unity first. You can try things right away without waiting for an upload.
  • If the parameter doesn't change, look at the menu and Expression Parameters. If the state doesn't change, look at the transitions. If what you see doesn't change, look at the clips and layers.
  • Once it works in Unity, check it yourself in VRChat, and finally ask a friend to look so you can confirm sync.
  • This is the last tip in "Building gimmicks yourself with the Animator". When you're stuck, use the list above to go back to each tip.
