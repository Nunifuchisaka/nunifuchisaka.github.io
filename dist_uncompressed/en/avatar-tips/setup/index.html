Avatar Tips #1

Installing VCC, ALCOM and Unity

To edit an avatar and upload it, you need Unity and a tool that sets up your projects (VCC or ALCOM). This tip explains what each one does, which one to choose, and how to install them, with recreated views of the screens.

Published November 3, 2026 · VRChat uses Unity 2022.3.22f1 (as of November 2026).

Read this when

  • You are editing an avatar for the first time.
  • You got a new PC and need to set it up for avatar editing again.
  • You are curious about ALCOM, for example because VCC feels slow or you want to edit on a Mac.

What to install

There are three things to install. You always need Unity Hub and Unity. For VCC and ALCOM, one of the two is enough.

Unity Hub
Software that installs and manages Unity. You also sign in with your Unity account here and activate the free license.
Unity 2022.3.22f1
The software you edit avatars in. Install the version VRChat specifies. If you install a newer version, you can't upload to VRChat.
VCC (VRChat Creator Companion)
VRChat's official tool. It creates projects, and installs and updates packages such as the VRChat SDK.
ALCOM
An unofficial tool that does the same things as VCC. It's fast, and it also runs on Mac and Linux. It shares its settings with VCC, so it's fine to install both.

  2. Unity 2022.3.22f1Install it with Unity Hub
  3. VCC or ALCOMCreate a project
  4. Open in UnityImport the avatar and edit

If you're on Windows and new to this, use VCC. It's official, so most download pages and guides assume you use VCC. You can also install Unity just by following its guide.

On Mac or Linux, use ALCOM. On Windows too, try ALCOM if VCC feels slow. Projects and repository settings are shared, so you don't need to recreate anything if you switch later.

Before you install

  • A Windows 10 or 11 PC. It needs to be powerful enough to run Unity.
  • Free disk space. Unity alone takes several GB, and each project can take several GB too. Leave plenty of room.
  • A Unity account (free). You sign in after installing Unity Hub. If you don't have one, create it on the Unity website.
  • Use only English letters and numbers in your PC name, user name and folder names. Avoid Japanese and other non-ASCII characters. They can cause errors in Unity. Name your projects with English letters and numbers too.

Installing with VCC (Windows)

Install VCC first, then follow its guide to install Unity Hub and Unity.

  1. Download the Creator Companion from VRChat's download page (opens in a new tab).
  2. Open the installer you downloaded. In "Select Setup Install Mode", choose "Install for me only (recommended)" and follow the steps.
  3. Open VCC and click "Settings" at the bottom left. If Unity Hub and Unity aren't installed, "Unity Editors" shows a warning. Click "Install Now".
  4. Click "Install Unity" and a guide to installing Unity Hub appears. Follow the link to the Unity website, then download and install Unity Hub.
  5. When Unity Hub opens, sign in with your Unity account. If Unity Hub asks whether to install Unity, don't install it here (VCC will do that).
  6. Go back to VCC and click "I have installed the Unity Hub". Then click "Install Unity 2022.3.22f1". If Windows asks "Do you want to allow this app to make changes to your device?", click "Yes".
  7. When the installation finishes, click "Continue".
  1. Appears when Unity Hub and Unity aren't installed. Click it to go to the Unity install screen.
  2. Click this after you install Unity Hub and sign in.
  3. Installs Unity 2022.3.22f1, the version VRChat uses, through Unity Hub. The Android components are installed along with it.

Activating your Unity license

To use Unity, you need to sign in to Unity Hub and activate a license. For personal use, the free Personal license is enough.

If you get a license error when you open Unity, add a license under "Licenses" in Unity Hub's settings (the gear icon). If that doesn't work, you can also create a license request file and activate it manually on the Unity website.

Installing with ALCOM (Windows, Mac, Linux)

ALCOM doesn't install Unity itself, so you install Unity with Unity Hub. ALCOM finds the Unity you installed automatically.

  1. Download the right file for your computer from the ALCOM website (opens in a new tab). For Windows it's an installer (.zip), and for Mac it's a disk image (.dmg).
  2. Open ALCOM and the first-time setup starts. In "Appearance", choose the language and look, then click "Next".
  3. In "Unity Hub", if Unity Hub isn't found, use "Download Unity Hub from unity.com" to install Unity Hub (opens in a new tab), then sign in. After installing it, click "Recheck Installation".
  4. In "Save Location", choose where to create projects. In "Backup Settings", choose where to keep backups. For both, pick a folder whose path has only English letters and numbers.
  5. On Windows, in "System Config", you can make ALCOM open from "Add to VCC" and similar buttons in your browser. When you see "Setup Completed!", click "Start using ALCOM".
  6. Install Unity 2022.3.22f1 with Unity Hub (see "Installing Unity with Unity Hub" below). After installing it, restart ALCOM.
  1. Shows where the Unity Hub it found is. If Unity Hub isn't installed, it says "not found".
  2. Opens the Unity website. Download and install Unity Hub, then sign in.
  3. Click this after you install Unity Hub. If it still isn't found, set the Unity Hub location yourself.
  4. Once Unity Hub is found, click this to go on to the next setting.

Installing Unity with Unity Hub

If you use ALCOM, or VCC couldn't install Unity properly, install 2022.3.22f1 with Unity Hub. The important part is to choose this version, not the latest one.

  1. Install Unity Hub and sign in.
  2. Open VRChat's "Current Unity Version" page (opens in a new tab) and click the link to install with Unity Hub. Unity Hub opens on the screen for installing 2022.3.22f1.
  3. Choose the components (modules) to install. If you'll also make avatars for Quest or phones, check "Android Build Support".
  4. Click "Install" and wait for it to finish.
  5. If the link doesn't open, go to "Installs" → "Install Editor" in Unity Hub and find 2022.3.22f1 in the list of older versions (Archive).
  1. Needed for avatars for Quest and Android. Also check OpenJDK and Android SDK & NDK Tools inside it.
  2. Needed for avatars for iOS devices such as iPhone.
  3. Needed on a Mac to make avatars for Windows (the PC version). You don't need it on Windows.
  4. Click this once you've chosen. It takes a while to finish installing.

Editing on a Mac

  • The VCC app with a window (GUI) is for Windows, so use ALCOM on a Mac.
  • Install the Mac versions of Unity Hub and Unity. To make avatars for the PC (Windows) version, add "Windows Build Support (Mono)".
  • Editing and uploading on a Mac isn't officially supported by VRChat. If things don't work, consider doing the work on a Windows PC.

Creating a project

Once everything is installed, create a project for your avatar and try opening it in Unity.

With VCC

  1. In "Projects" on the left, click "Create New Project".
  2. Choose the "Avatars" template.
  3. Enter a project name (English letters and numbers) and choose where to save it, then click "Create Project".
  4. Click "Open Project" on the project in the list to open it in Unity.

With ALCOM

  1. In "Projects", click "Create New Project".
  2. Choose the "VRChat Avatars" template and check that the Unity version is 2022.3.22f1.
  3. Enter a name (English letters and numbers). When you see "Ready to create a project!", click "Create".
  4. Click "Open Unity" on the project in the list to open it in Unity.

Opening it the first time takes a while. Once it opens, check that "VRChat SDK" is in the menu at the top. Import avatars and outfits after that.

Adding tools and shaders

Many tools and shaders used for avatar editing are installed with VCC or ALCOM, as packages. Click the "Add to VCC" button on a download page to add the source (repository). The same button works with ALCOM.

If there's no button, copy the URL from the download page and enter it in "Settings" → "Packages" → "Add Repository" in VCC, or "Add Repository" in ALCOM.

After adding it, open "Manage Project" for your project ("Manage" in ALCOM) and install the packages you want.

Common problems

Unity Hub recommends a newer version

What happens
Unity Hub keeps recommending that you install a newer version. Older versions show a security warning.
How to fix it
Close it without installing. Keep your VRChat projects on 2022.3.22f1. VRChat also says this warning doesn't apply to VRChat avatars and worlds.

It says Unity can't be found

What happens
VCC or ALCOM says Unity can't be found. Projects won't open.
How to fix it
Check in Unity Hub that 2022.3.22f1 is installed. If it is, set the Unity location: in VCC, under Unity Editors in "Settings"; in ALCOM, with "Add Unity" in "Settings". ALCOM may also find it after you restart it.

Unity won't open because of a license error

What happens
When you try to open Unity, it says you don't have a license.
How to fix it
Check that you're signed in to Unity Hub, and add the free license under "Licenses".

Unity Hub won't install

What happens
Installing Unity Hub or Unity stops partway or fails.
How to fix it
Click "Yes" when Windows asks for permission. If that doesn't help, right-click the installer and choose "Run as administrator".

Errors appear in the project

What happens
Lots of errors appear when you create or open a project.
How to fix it
Check that the project name and the names of the folders it's saved in have no Japanese or other non-ASCII characters. It can also happen when your PC name or user name has them (ALCOM shows "Bad hostname").

VCC is slow, or packages won't install

What happens
VCC takes a long time to start or to install packages.
How to fix it
Try ALCOM. It shares settings with VCC, so you can open the same projects as they are.

Things to watch out for

  • Don't upgrade Unity from 2022.3.22f1. VRChat has been running an open beta for Unity 6 since June 2026, but you can't upload anything made with Unity 6 yet. When VRChat changes the version, follow its official announcement.
  • Install VCC, ALCOM and Unity Hub from their official download pages.
  • ALCOM is not an official VRChat tool. If you have trouble with ALCOM, ask the ALCOM developers, not VRChat.
  • Back up your project before editing, just to be safe. Both VCC and ALCOM can make project backups.

Summary

  • Always install Unity Hub and Unity 2022.3.22f1. Don't install a newer version.
  • Use VCC if you're on Windows and new to this. Use ALCOM on Mac or Linux, or when VCC feels slow.
  • Use only English letters and numbers in your PC name, folders and project names.
  • Create a project and open it in Unity. If the "VRChat SDK" menu is there, you're ready.
