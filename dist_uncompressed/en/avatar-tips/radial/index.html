Avatar Tips #9

Switching in steps and changing gradually

Pick one outfit out of several, or turn a menu dial to change a hat's size or color bit by bit. After on/off toggles, the next step is gimmicks that use Int and Float parameters. This tip walks you through it one click at a time: switching from Any State, Radial Puppet and Motion Time, Blend Trees, and how it looks to others.

Published November 3, 2026 · Covers Unity's Built-in Render Pipeline and VRChat avatars (Avatars 3.0). Up to date as of November 2026.

When to read this

  • You've prepared a few outfits and want to pick one from the menu to change into. You don't want two to show at once.
  • You want to change the size of a hat or tail, or your hair color, bit by bit by turning a menu dial.
  • You don't know whether to use Bool, Int, or Float.
  • You turned the dial, but to others it looks a little late, or it changes in steps.

This tip assumes you built the hat toggle in #8 Building a menu toggle. Making the controller, setting Weight to 1, and hooking it up with Modular Avatar (MA) all work the same way as there.

Choosing Bool, Int, or Float

Parameters come in three types. Pick one based on what you want to do. #6 How the Animator works explains parameters themselves.

TypeValuesSync costGood forMenu item
Booltrue or false1 bitShowing or hiding one thingToggle
IntWhole numbers from 0 to 2558 bitsPicking one of severalA Toggle or Button for each value
FloatDecimals from -1 to 1 (0 to 1 with a Radial Puppet)8 bitsChanging size or color bit by bitRadial Puppet
  • If it's only show or hide, use Bool. It uses the least budget.
  • To pick just one of several outfits, use Int. It holds only one value, so two outfits never show at once. For three outfits, three Bools would cost less (3 bits). But then two could be on at the same time. The more choices you have, the better Int becomes.
  • If you want in-between values, use Float. Pair it with a Radial Puppet (a menu item with a round dial you turn).
  • The sync budget is 256 bits in total for the whole avatar.

Pick one of three outfits with an Int

Say your avatar has three outfits: Outfit_A, Outfit_B, and Outfit_C. The names are examples. The value of an Int parameter, OutfitNo, decides which one shows. At 0, all three are hidden.

OutfitNoState (clip)Outfit_AOutfit_BOutfit_C
0Outfit_00 (off)0 (off)0 (off)
1Outfit_11 (on)0 (off)0 (off)
2Outfit_20 (off)1 (on)0 (off)
3Outfit_30 (off)0 (off)1 (on)

Create the clips and the controller

  1. In the Project window, right-click your own folder (for example, MyGimmicks/Outfit), choose Create → Animation, and make four clips: Outfit_0 to Outfit_3. You'll record what goes inside them later.
  2. In the same folder, choose Create → Animator Controller, make Outfit_FX, and double-click it to open it.
  3. Click the + in Layers to add a layer named Outfit, and set its Weight to 1 from the gear.
  4. Click the + in Parameters, choose Int, and name it OutfitNo.
  5. Select the Outfit layer and drag in Outfit_0 first, so it becomes the orange first state. Then drag in Outfit_1 to Outfit_3.

Record the clips

  1. Select the top of your avatar. In the Inspector, put Outfit_FX in the Controller field of the Animator, only while you record (the same as in the previous tip).
  2. In the Animation window (Window → Animation → Animation), choose Outfit_1 from the clip name field.
  3. Click the record button. Turn Outfit_A on, and turn Outfit_B and Outfit_C off. (If you switch a checkbox and switch it back, a key is added even when the value ends up the same.) Check that all three rows are there, then stop recording.
  4. Record Outfit_0, Outfit_2, and Outfit_3 as shown in the table above.
  5. When you're done, put the outfits' on/off state and the Controller field of the Animator back the way they were.

Put rows for all three outfits in every clip. If Outfit_2 has no Outfit_A row, then on avatars with Write Defaults OFF, Outfit_A stays visible from before, and two outfits overlap.

Transitions from Any State

  1. In the Animator window, right-click the light blue Any State, choose Make Transition, and click Outfit_1.
  2. Select the arrow and uncheck Has Exit Time in the Inspector. Open Settings, set Transition Duration to 0, and uncheck Can Transition To Self.
  3. Click the + under Conditions and set it to OutfitNo, Equals, 1.
  4. In the same way, draw arrows from Any State to Outfit_0, Outfit_2, and Outfit_3, and set their Equals numbers to 0, 2, and 3.
  1. If you leave this checked, the layer re-enters Outfit_1 every frame while OutfitNo is 1.
  2. For an Int, use Equals to send each value to its own state.

Any State is an entry point that means "from whatever state you're in now." An arrow from here moves to its state whenever the condition is met, wherever the layer is. Connecting four states to each other with arrows takes 12 arrows, but from Any State you only need 4.

If Can Transition To Self stays checked, the layer keeps re-entering the same state the whole time the condition is met. With clips that only turn things on and off, you may not see a difference, but clips with motion keep jumping back to the start. Uncheck it.

Pick one from the menu

Hooking it up with MA works the same as in the previous tip. Make an object named Outfits inside your avatar, and add MA Merge Animator (Outfit_FX, FX, Absolute, Match Avatar Write Defaults) and MA Parameters.

  1. Add OutfitNo to MA Parameters and set its type to Int. Set Default Value to the number of the outfit you start in (0 if you start with none). Check Saved and Synced.
  2. Add MA Menu Installer and MA Menu Item to Outfits, and set the Menu Item's Type to Sub Menu. Choose to build the inner menu from this object's children (the option labeled something like Children).
  3. Right-click Outfits and choose Create Empty Child to make three children. Name them Uniform, Hoodie, and Dress. These are the names shown in the menu.
  4. Add MA Menu Item to each of the three children, and set Type to Toggle and Parameter to OutfitNo. Set Value to 1 for Uniform, 2 for Hoodie, and 3 for Dress.
  1. Pressing it opens another menu inside. The three children are listed there.
  2. Pressing it sets OutfitNo to 2. Give each item a different number.

When a Toggle turns on, it sets the Parameter to its Value. When it turns off, it sets it back to 0. Press "Hoodie" and OutfitNo becomes 2, so the layer moves to Outfit_2.

Then press "Dress" and it becomes 3. OutfitNo is no longer 2, so the "Hoodie" item shows as off on its own. That's why only one can be picked.

Press the selected "Dress" again, and it goes back to 0. All three outfits are hidden.

When you add it to your avatar's FX directly, add an Int row in Expression Parameters. Then click Add Control in the Expressions Menu, set Type to Sub Menu, and put three Toggles in the inner menu's file. For details, see VRChat's Expressions Menu page (opens in a new tab).

Change things gradually with Float and Radial Puppet

Change the hat's size by turning a dial in the menu. A Float parameter, HatSize (0 to 1), decides "which point to play" in a single clip. This is Motion Time.

  1. Turn the Radial PuppetHatSize = 0 to 1
  2. The state's Motion TimeUses HatSize as the position in the clip
  3. Frames 0 to 60 of the clip0.5 means frame 30
  4. ResultThe hat takes the size at that position

Create the clip and state, and set Motion Time

  1. In the Project window, choose Create → Animation and make Hat_Size. You'll record what goes inside it later.
  2. Make HatSize_FX with Create → Animator Controller and open it. Add a layer named HatSize and set its Weight to 1.
  3. Click the + in Parameters, choose Float, and name it HatSize.
  4. Drag Hat_Size into the Animator window to make a state. It becomes the orange first state. You don't need any transitions.
  5. Select the state. In the Inspector, check Parameter on the Motion Time row, and choose HatSize in the field to the right.
  6. Match Write Defaults to the other states. (If you use MA's Match Avatar Write Defaults, it matches them for you.)
  1. Instead of playing the clip over time, the state stops at the position given by HatSize. 0 is the start, and 1 is the end.

Add keys at the start and the end

  1. Put HatSize_FX in the Controller field of the Animator on the top of your avatar, only while you record. Choose Hat_Size in the Animation window and click the record button.
  2. Check that the frame field (the number to the right of the play button) is 0. Select Hat in the Hierarchy, and in the Inspector, set the Transform's Scale to 0.5 for X, Y, and Z.
  3. Type 60 in the frame field to move to frame 60. Set Scale to 1.5 for X, Y, and Z. Stop recording.
  4. Click Curves at the bottom of the Animation window, select all the keys, right-click, and choose Both Tangents → Linear. Now the value changes at a steady rate between the keys. (If you leave it as is, it may become a curve that changes slowly near the ends.)
  5. Select Hat_Size in the Project window and uncheck Loop Time in the Inspector. If it stays checked, the very end (1) may look like it jumps back to the starting shape.
  6. Check that the Scale of Hat is back to how it was before recording, and put the Controller field of the Animator back.

Changing color works the same way. At frames 0 and 60, add keys on the material's color row (a row like Mesh Renderer : Material._Color. The name depends on the shader).

Hook it up to your avatar and add it to the menu

  1. To hook it up with MA, make an object named Hat Size, and add MA Merge Animator (HatSize_FX) and MA Parameters. Add HatSize as a Float, set Default Value to 0.5 (which is Scale 1.0), and check Saved and Synced.
  2. Add MA Menu Installer and MA Menu Item, and set Type to Radial Puppet. Put HatSize in the field for the value you turn (the field labeled Rotation).
  3. In VRChat, pressing this item opens a dial. Turning it changes HatSize from 0 to 1.

Another way: Blend Tree (1D)

A Blend Tree blends several clips together based on a parameter's value. You can use it instead of Motion Time.

  1. In the Project window, make two empty clips: Hat_Small and Hat_Big.
  2. Right-click an empty spot in the HatSize layer and choose Create State → From New Blend Tree. You'll use it instead of the Motion Time state, so right-click it and choose Set as Layer Default State.
  3. Double-click the new state to see the Blend Tree inside. Click it.
  4. In the Inspector, set Blend Type to 1D and Parameter to HatSize.
  5. Choose Add Motion Field twice from the + under Motion, and put in Hat_Small and Hat_Big.
  6. Uncheck Automate Thresholds, and set the Threshold to 0 for Hat_Small and 1 for Hat_Big.
  7. Record the same way as above: a Scale 0.5 key in Hat_Small and a Scale 1.5 key in Hat_Big, only at frame 0. The Blend Tree blends between them, so you don't need to set the keys to Linear.

Which to use: Motion Time needs only one clip, so it's quicker to build. A Blend Tree is a better fit when you also want to set the shape in the middle (three shapes: small at 0, normal at 0.5, and big at 1), or when you want to keep the clips separate.

Blend Trees work when the parameter is a Float. VRChat may convert the value when the type differs between Expression Parameters and the Animator. For example, you can make it a Bool in Expression Parameters, and use the same name as a Float in the Animator for a Blend Tree.

Try it out

Move the value as if you were turning a Radial Puppet. With Motion Time, you'll see which point in the 60-frame clip is used, and how the hat looks.

Sync, precision, and how others see it

Bool and Int values reach others exactly. If OutfitNo is 2, it's 2 on other people's screens too.

Float values are rounded to 8 bits when they're sent to others. The range from -1 to 1 is split into about 255 steps, so each step is about 1/127. 0.503 on your screen might be 0.504 for others. For size or color, you'll hardly notice.

Values arrive a little late. If you turn the dial quickly, others may see it lag behind, or change in steps.

The official docs say that while a dial (like a Radial Puppet) is open and you're turning it, the value is sent often and smoothed out on the other person's side. But how smooth it looks depends on things like the connection. The value you end on does reach others. It's safest to assume the motion in between won't look exactly the same.

For the detailed rules, see VRChat's Animator Parameters page (opens in a new tab).

ParameterTypeSync cost
HatOnBool1 bit

Total17 bits (up to 256 bits allowed)
  • Parameters with Synced unchecked use none of the budget. Instead, others keep seeing the Default. Use this for things only you need to see.
  • If you go over 256 bits, you can't upload. Places like the Expression Parameters Inspector show how much you're using.

Common problems and fixes

Two outfits show at once

What happens
You picked a different outfit, but the previous one doesn't go away, and they overlap.
Cause
The clip has no rows for the other outfits (Is Active at 0). Write Defaults is OFF, so the previous value stays.
Fix
Put Is Active rows for all three outfits in every clip, from Outfit_0 to Outfit_3.

Picking an outfit doesn't switch anything

What happens
You press an outfit in the menu, but nothing changes.
Cause
The Animator parameter's name or type (Int) is different, or the Equals number on an arrow from Any State is wrong. The layer's Weight may also be 0.
Fix
Match the name and type between MA Parameters and the Animator. Check that the arrows' numbers match the menu's Values.

A clip with motion keeps playing from the start

What happens
You added an animation like swaying to an outfit, but it looks stuck in its first pose.
Cause
Can Transition To Self is checked on the arrows from Any State. The layer re-enters the state every frame.
Fix
Uncheck Can Transition To Self on every arrow from Any State.

Turning the dial doesn't change the size

What happens
You turn the Radial Puppet, but the hat's size doesn't change.
Cause
Parameter isn't checked on the state's Motion Time, or the clip only has a key at frame 0.
Fix
Check Motion Time and choose HatSize. Add keys at both frame 0 and the end of the clip.

At the largest size, it snaps back to small

What happens
When you turn the dial all the way, the hat takes its smallest shape.
Cause
Loop Time is checked on the clip, so the end connects back to the start.
Fix
Select the clip in the Project window and uncheck Loop Time in the Inspector.

It changes fast in the middle and slowly at the ends

What happens
It doesn't change as much as you turn, and barely changes near the ends.
Cause
The curve between the keys flattens out at the ends.
Fix
In the Animation window, open Curves and select the keys. Right-click and choose Both Tangents → Linear.

It looks late to others

What happens
It changes smoothly for you, but a friend says it looks late and changes in steps.
Cause
Float values arrive a little late over the network, and they're rounded to 8 bits.
Fix
This is normal. If the value you end on matches, it's fine. If you want to show fast motion, build it so the clip itself plays, instead of turning a Float.

Things to watch out for

  • When you switch with an Int, put rows for everything you switch in every clip.
  • Uncheck Can Transition To Self on arrows from Any State.
  • For clips used with Motion Time, uncheck Loop Time and add keys at the start and the end.
  • Floats are rounded to 8 bits and reach others a little late. For things that need exactly the same value, split them into steps with an Int.
  • The sync budget is 256 bits for the whole avatar. Parameters added by other tools, like outfit gimmicks, count too.
  • To change size, move the Scale of the accessory object, not Humanoid bones.

Summary

  • Use Bool for on/off, Int to pick one of several, and Float to change things gradually.
  • With an Int, move to each state from Any State with an Equals condition. Uncheck Can Transition To Self.
  • A menu Toggle sets its Value when on, and 0 when off. Make one item for each value, and only one can be picked.
  • Turn a Float with a Radial Puppet, and use the state's Motion Time to turn it into a position in the clip. You can also build it with a Blend Tree.
  • Floats are rounded to 8 bits and reach others a little late.
