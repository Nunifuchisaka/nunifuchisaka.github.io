アバター改変の解説 第12回

ギミックが動かないとき

メニューを押しても動かない。自分にしか見えない。ワールドを移ると元に戻る。ギミックが思ったとおりに動かないときに、どこから、どの順番で確かめればよいかと、よくある原因の一覧をまとめました。困ったときは、まずこのページに来てください。

公開 2026年11月3日 · 対象は Unity の Built-in Render Pipeline と VRChat のアバター（Avatars 3.0）です。2026年11月時点の内容です。

こんなときに読んでください

  • 自分で組んだギミックが、メニューを押しても動かない。
  • 自分には見えるのに、ほかの人には見えないと言われた。
  • ワールドを移ったり、アバターを着替えたりすると、オンオフが元に戻る。
  • Unity では動いたのに、VRChat では動かない。
  • どこが悪いのか分からず、何から見ればよいか分からない。

確かめる順番

ギミックは、メニュー → パラメーター → ステート → クリップ → 見た目 の順に、値が受け渡されて動きます（くわしくは第6回 Animator のしくみ）。どこかで受け渡しが止まると、その先は動きません。

そこで、前から順に、どこまで届いているかを1つずつ確かめます。止まったところのすぐ手前に、原因があります。思いつくところを手当たりしだいに直すより、ずっと早く見つかります。

そして、まず Unity で確かめます。VRChat で試すには、毎回アップロードして待つ必要があります。Unity なら、直して再生するだけで、すぐ確かめられます。

  1. 1. Unity で再生Gesture Manager でメニューを押す
  2. 2. パラメーター値が変わるか
  3. 3. ステート入るステートが変わるか
  4. 4. クリップ正しいものを書いているか
  5. 5. VRChat で自分アップロードして試す
  6. 6. 友だちとほかの人にも見えるか

それぞれで見るところと、止まったときに見る場所

1. Unity で、Gesture Manager を使って再生する
次の節の手順で、Unity の再生ボタンを押し、Gesture Manager のメニューから、そのギミックの項目を押します。Unity で動けば、Animator やクリップの組み方は合っています。5 へ進みます。Unity でも動かなければ、2 から順に見ます。
2. パラメーターの値は変わっているか
メニューを押したときに、Gesture Manager の Debug の欄で、そのパラメーターの値が変わるかを見ます。変わらないなら、メニューと Expression Parameters が原因です。名前が合っているか、Expression Parameters にそのパラメーターがあるかを見ます。
3. 入るステートは変わっているか
パラメーターは変わるのに、ステートが変わらないなら、Animator のパラメーターの名前か、トランジションの条件が原因です。Animator ウィンドウで、そのレイヤーの動いているステートを見ます（見方は次の節）。
4. クリップは正しいものを書いているか
ステートは変わるのに、見た目が変わらないなら、クリップの中身か、レイヤーの設定が原因です。クリップのパスが切れていないか（Missing）、レイヤーの Weight が 0 でないか、下のレイヤーが同じものを書いていないかを見ます。
5. VRChat で、自分で確かめる
Unity で動いたら、アップロードして VRChat で試します。Unity で動くのに VRChat で動かないなら、アップロードのときに外されたもの（EditorOnly のオブジェクトなど）や、アップロード先のアバターを見ます。
6. 友だちに、ほかの人からの見え方を見てもらう
自分で動いたら、友だちに見てもらいます。Gesture Manager も自分の画面も、自分から見た姿しか確かめられません。ほかの人に見えないなら、パラメーターの Synced（ほかの人に送る）や、Quest 版を見ます。

どの段で止まったかが分かったら、下の「よくある原因の一覧」で、その困りごとを選ぶと、見る場所が絞れます。

確かめる道具

確かめるのに使う道具は、おもに3つです。Unity の Gesture Manager、Unity の Animator ウィンドウ、VRChat の中の表示です。

Gesture Manager（Unity で、VRChat のように動かす）

Gesture Manager は、Unity で再生したときに、アバターの Animator を VRChat と同じように動かす道具です。メニュー（Expressions Menu）やハンドサインを、Unity の中で試せます。作者は BlackStartx さんです（Gesture Manager の配布ページ（新しいタブで開きます））。

VCC か ALCOM で、プロジェクトの一覧から Gesture Manager を足して入れます。足し方は第1回 VCC・ALCOM・Unity の入れ方を見てください。

  1. Unity の上のメニューで Tools → Gesture Manager Emulator を押します。シーンに GestureManager というオブジェクトが入ります。これは確かめるためだけのもので、アップロードには入りません。
  2. Unity の上の真ん中にある再生ボタン（▶）を押します。Unity が再生の状態になり、Animator が動き出します。
  3. Hierarchy で GestureManager を選びます。Inspector に、VRChat と同じ形の丸いメニューが出ます。アバターが2体以上あるときは、試すアバターを選びます。
  4. 丸いメニューで、試したいギミックの項目を押します。見た目が変わるかを、Scene か Game の画面で見ます。
  5. Inspector の上のほうにある Debug の欄を開きます。パラメーターの値、レイヤーの Weight、いま入っているステートが並びます。メニューを押して、どの値が変わるかを見ます。
  6. 確かめ終わったら、もう一度再生ボタンを押して、再生を止めます。再生中に変えた設定は、止めると元に戻ります。直すのは、止めてからにします。
  1. メニューで帽子をオンにすると、Hat が true になりました。メニューと Expression Parameters は合っています。
  2. Hat のレイヤーの Weight が 0 です。これでは、ステートが変わっても見た目は変わりません。Weight を 1 にします。
  3. ステートは Hat_On に入っています。トランジションも合っています。

Gesture Manager の画面の名前や並びは、版によって違うことがあります。欄が見つからないときは、Inspector の中のボタンを1つずつ押してみてください。

Animator ウィンドウ（いま動いているステートを見る）

  1. Gesture Manager で再生している間に、Hierarchy でアバター（いちばん上の、VRC Avatar Descriptor が付いたオブジェクト）を選びます。
  2. Window → Animation → Animator で、Animator ウィンドウを開きます。Gesture Manager の Debug から、見たいレイヤー（FX など）を開けることもあります。
  3. 左の Layers のタブで、見たいレイヤーを選びます。
  4. いま入っているステートは、青い進み具合のバーが下に出て、動いて見えます。メニューを押すと、バーが別のステートへ移るかを見ます。移らなければ、トランジションの条件か、パラメーターの名前が違います。
  5. トランジションの矢印を選ぶと、Inspector に、その条件（Conditions）が出ます。パラメーターの名前と値が合っているかを見ます。

再生中に Animator ウィンドウで変えた設定も、再生を止めると元に戻ることがあります。何をどう変えれば直るかが分かったら、止めてから、同じように直してください。

VRChat の中の表示

VRChat の中でも、アバターのパラメーターの値を見られる表示があります。Expressions メニュー（Action Menu）の中の設定（Options）のあたりに、デバッグ用の表示（Debug）を出す項目があります。名前や場所は VRChat の更新で変わることがあるので、見つからないときは、VRChat の公式のドキュメントで最新の場所を確かめてください。

VRChat SDK の Builder には、アップロードせずに、自分のパソコンの VRChat だけで試す方法（Build & Test）もあります。毎回アップロードするより早く試せます。

ほかの人からの見え方は、ほかの人にしか確かめられません。同期（Synced）や Quest 版を確かめるときは、友だちに頼んで、同じワールドで見てもらいます。Quest やスマホの友だちがいれば、その人にも見てもらうと安心です。

よくある困りごとと直し方

Unity でも、メニューを押して何も起きない

起きること
Gesture Manager でメニューを押すと、パラメーターもステートも変わる。でも、見た目が変わらない。
原因
いちばん多いのは、自分で足したレイヤーの Weight が 0 のままのことです。Unity でレイヤーを足すと、Weight は 0 で作られます。
直し方
Animator ウィンドウの Layers で、そのレイヤーの歯車を押し、Weight を 1 にします。それでも変わらなければ、クリップのパスと、下のレイヤーを見ます。

自分にしか見えない

起きること
自分の画面では帽子が出ている。友だちからは、帽子が無いと言われる。
原因
Expression Parameters で、そのパラメーターの Synced のチェックが外れています。値がほかの人に送られていません。
直し方
Synced にチェックを入れて、アップロードし直します。友だちが Quest やスマホなら、Android 版にもギミックが入っているかを見ます。

ワールドを移ると、オフに戻る

起きること
帽子をオンにしても、ワールドを移ると、帽子が消えている。
原因
Expression Parameters で、そのパラメーターの Saved のチェックが外れています。ワールドを移ると、Default の値に戻ります。
直し方
Saved にチェックを入れて、アップロードし直します。

オンにすると、ぱたぱた点滅する

起きること
オンにすると、帽子が出たり消えたりを、細かく繰り返す。
原因
Any State からのトランジションで、Can Transition To Self にチェックが入っています。条件が合っている間、同じステートに入り直し続けています。
直し方
Any State からの矢印を選び、Can Transition To Self のチェックを外します。

Unity では動くのに、VRChat では出ない

起きること
Gesture Manager では帽子が出る。アップロードして VRChat で押すと、出ない。
原因
帽子のオブジェクトのタグが EditorOnly になっていて、アップロードのときに外されています。別のアバターにアップロードしていることもあります。
直し方
Tag を Untagged にして、アップロードし直します。Builder で、アップロード先のアバターも見ます。

パラメーターが多すぎて、アップロードできない

起きること
ギミックを足したら、Builder に、パラメーターが多すぎるという注意が出て、アップロードできない。
原因
同期するパラメーターの合計が、256 bit を超えています。衣装やツールが足したパラメーターも数に入ります。
直し方
使っていないパラメーターを消すか、ほかの人に見せなくてよいものの Synced を外します。服の切り替えのように、いくつかのオンオフは Int 1つ（8 bit）にまとめられます。

気をつけること

  • 一度に直すのは1か所だけにします。いくつも同時に変えると、どれで直ったのか、どれで壊れたのかが分からなくなります。
  • 直す前に、元に戻せるようにしておきます。コントローラーやクリップを複製しておくか、アバターのフォルダを書き出しておきます。
  • Unity で再生している間に変えた設定は、再生を止めると元に戻ります。直すのは、再生を止めてからにします。
  • Gesture Manager で動いても、ほかの人からの見え方（同期）は確かめられません。最後は、VRChat で友だちに見てもらいます。
  • 買ったアバターの FX やメニューに直接足すと、アバターの更新で消えることがあります。自分で作ったものは、MA でつなぐ形にしておくと安心です。
  • VRChat の中のデバッグ表示や、Gesture Manager の画面は、更新で名前や場所が変わることがあります。

まとめ

  • ギミックは、メニュー → パラメーター → ステート → クリップ → 見た目 の順に動きます。前から順に、どこまで届いているかを確かめます。
  • まず Unity の Gesture Manager で確かめます。アップロードを待たずに、すぐ試せます。
  • パラメーターが変わらないならメニューと Expression Parameters、ステートが変わらないならトランジション、見た目が変わらないならクリップとレイヤーを見ます。
  • Unity で動いたら VRChat で自分で、最後に友だちに見てもらって、同期を確かめます。
  • これで「Animator でギミックを自分で作る」の回はおしまいです。困ったら、上の一覧から、それぞれの回に戻ってください。
