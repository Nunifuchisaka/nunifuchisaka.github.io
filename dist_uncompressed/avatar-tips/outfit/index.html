アバター改変の解説 第3回

衣装を着せる

買った衣装をアバターに着せる手順を解説します。いまは Modular Avatar（モジュラーアバター）を使うと、ほとんどの衣装が数クリックで着せられます。体が服から突き抜けるときの直し方や、メニューで服をオンオフする方法も、再現図と動かして確かめられる図つきで説明します。

公開 2026年11月3日 · 対象は VRChat のアバター（Avatars 3.0）と Modular Avatar です。2026年11月時点の内容です。

こんなときに読んでください

  • BOOTH などで買った衣装を、自分のアバターに着せたい。
  • 衣装を着せたのに、動くと服がついてこない。体が服から突き抜ける。
  • 服をメニューで着たり脱いだりできるようにしたい。

着せる前に確かめること

衣装には、どのアバター向けに作られたかが決まっています。説明書や販売ページで確かめてください。

対応アバター
販売ページに「対応アバター」として名前があれば、そのアバターに合わせて作られています。このページの手順で、ほぼそのまま着せられます。
非対応のアバター
名前が無いアバターにも着せられることはありますが、大きさや形を自分で合わせる必要があります。難しいので、はじめは対応アバターの衣装から試してください。
必要なシェーダー
多くの衣装は lilToon などのシェーダーを使います。説明書に書かれたシェーダーを、先にプロジェクトに入れておきます。
利用規約
改変してよい範囲や、アップロードの条件は衣装ごとに違います。使う前に読んでおきます。

Modular Avatar を使う理由

昔は、衣装のボーン（骨）をアバターのボーンの中に1本ずつ入れ直して着せていました。手間がかかるうえ、まちがえると元に戻すのが大変で、アバターや衣装を更新するとやり直しになりました。

Modular Avatar は、アップロードするときや Unity で再生したときだけ、衣装のボーンをアバターのボーンに自動でまとめます（Merge Armature）。編集中のアバターや衣装はそのままなので、こわしません。衣装を外したいときは、Hierarchy から衣装を消すだけです。

  1. 衣装をアバターの中に置くHierarchy でドラッグ
  2. Setup OutfitMerge Armature が付く
  3. 再生・アップロードボーンが自動でまとまる
  4. 体に沿って動く元のデータはそのまま

Modular Avatar を入れる

Modular Avatar は、VCC か ALCOM でプロジェクトに入れます。VCC と ALCOM の入れ方は、第1回で解説しています。

  1. Modular Avatar の公式サイト（新しいタブで開きます）の「インストール」で、VCC なら「Modular AvatarをVCCに追加」を押します。ALCOM なら「VPMリポジトリを追加」に https://vpm.nadena.dev/vpm.json を入れます。
  2. VCC は「Manage Project」、ALCOM は「管理」でプロジェクトを開き、Modular Avatar の + を押して入れます。

衣装を着せる手順

  1. 衣装の unitypackage を、Unity の Project ウィンドウにドラッグして、「Import」を押します。
  2. 衣装のフォルダから、アバター名の付いたプレハブ（Prefab）を探します。対応アバターごとにプレハブが分かれていることが多いです。
  3. そのプレハブを、Hierarchy のアバター（VRC Avatar Descriptor が付いたもの）の上にドラッグして、アバターの子にします。
  4. 衣装を右クリックして、[ModularAvatar] Setup Outfit を選びます。
  5. 元から着ていた服をオフにします（Inspector の左上のチェックを外します）。
  6. Unity の再生ボタンを押して、アバターを動かしても服がついてくるかを確かめます。
  1. 衣装のプレハブを、アバターのすぐ下（子）に置きます。アバターの外や、Armature の中に置かないでください。
  2. 衣装を右クリックして選びます。衣装の中の Armature を見つけて、Merge Armature を付けてくれます。

Setup Outfit がしていること

Setup Outfit を選ぶと、衣装の中の Armature に MA Merge Armature が付き、衣装のいちばん上に MA Outfit Root が付きます。

Merge Armature は、衣装のボーンを名前で探して、アバターの同じ名前のボーンにまとめます。アバターに無いボーン（スカートの骨など）は、アバターのボーンの子として足されます。衣装の揺れもの（PhysBone）も、まとめた先のボーンを動かすように直されます。

まとめるのは、再生したときとアップロードするときだけです。再生をやめると、Hierarchy は元の形に戻ります。

  1. 衣装のボーンをまとめる先です。アバターの Armature が入ります。Setup Outfit が自動で入れるので、ふつうは変えません。
  2. 編集中に、アバターのポーズに合わせて衣装も動かす設定です。Setup Outfit では、この一方向の設定になります。
  3. アバターに無いボーンの名前を変えて、ほかのアイテムのボーンとぶつからないようにします。

体が服から突き抜けるとき

体の形が服より大きいと、動いたときに肌が服から突き抜けます。多くのアバターには、服の下の体を縮めたり消したりする BlendShape（シェイプキー）があります。名前は Shrink_〜 や Hide_〜 などで、アバターの説明書に書かれています。

Body の Skinned Mesh Renderer で、この BlendShape の値を上げれば縮みます。ただし、この値は服を脱いでも縮んだままです。また、アバターの FX の Animator がこの BlendShape を書いていると、VRChat では Unity で入れた値に戻ってしまいます（第13回）。

おすすめは、衣装の中に MA Shape Changer を付ける方法です。衣装がオンのときだけ、体の BlendShape を決めた値にします。衣装をオフにすると、体は元に戻ります。Delete にすると、服の下の体のポリゴンを消して、軽くすることもできます。

  1. 縮めたい体のメッシュ（ふつうは Body）を入れます。
  2. Set は、衣装がオンのときに、この値にします。縮める BlendShape に使います。
  3. Delete は、衣装がオンのときに、この BlendShape がかかる部分を消します。服で完全に隠れる部分に使います。

動かして確かめる

体の縮小の値と縮め方を変えて、服を着たとき、脱いだときの見た目を比べてみてください。FX の Animator はこの BlendShape を書いていないものとします。

縮め方

Body に入れた値は、服を着ていても脱いでいても同じです。

服を着ているとき：体が服から突き抜けています。値を上げてください。

服を脱いだとき：体が元の形に戻ります。

メニューで服を着たり脱いだりする

Modular Avatar を使うと、Animator を自分で作らなくても、Expressions Menu（Action Menu）に服のオンオフを足せます。

  1. Hierarchy でアバターを右クリックして、Modular Avatar → Create Toggle を選びます。アバターの子に、Menu Item、Menu Installer、Object Toggle が付いたオブジェクトができます。
  2. オブジェクトの名前を、メニューに出したい名前（たとえば「ドレス」）にします。この名前がメニューの項目名になります。
  3. Object Toggle の + を押して、衣装のオブジェクトをドラッグします。右のチェックを入れると「選んだときにオン」、外すと「選んだときにオフ」です。
  4. 最初から着ている服なら、Menu Item で「初期設定にする」を押して、はじめはオンにしておきます。
  5. 衣装の中の Shape Changer は、衣装のオンオフに合わせて動きます。脱ぐと、体が元に戻ります。

Animator を自分で組んで、オンオフのしくみから作る方法は、第8回 メニューでオンオフするギミックを作るで解説しています。

再生して確かめる

  • Unity の再生ボタンを押すと、Modular Avatar が衣装をまとめた状態になります。Scene でアバターのポーズを動かして、服がついてくるか、突き抜けないかを見ます。
  • Gesture Manager を入れておくと、再生中に Expressions Menu を開いて、服のオンオフも試せます。
  • 大丈夫なら、アップロードして VRChat でも確かめます。鏡の前で、しゃがむ、腕を上げるなど、大きく動いてみてください。

よくある困りごと

服がついてこない

起きること
再生したり VRChat で動いたりすると、服がその場に残る。
原因
Setup Outfit をしていないか、衣装がアバターの子になっていません。
直し方
衣装をアバターのすぐ下に置き、右クリックから Setup Outfit をし直します。衣装の Armature に MA Merge Armature が付いているかも確かめます。

体が服から突き抜ける

起きること
動いたときに、胸やおなか、太ももの肌が服の外に出る。
原因
服の下の体が大きいままです。
直し方
体を縮める BlendShape を、MA Shape Changer で衣装に付けます。Body に直接値を入れた場合は、FX の Animator が値を書いていないかも確かめます（第13回）。

服が浮く・大きさが合わない

起きること
服が体から離れて浮いている。袖や裾の長さが合わない。
原因
対応していないアバター用のプレハブを使っているか、アバターの体型を変えています。
直し方
自分のアバター用のプレハブかを確かめます。体型を BlendShape で変えているときは、衣装側の同じ BlendShape を合わせるか、MA Blendshape Sync で同じ値にします。

揺れものが二重にかかる

起きること
胸や髪の揺れ方がおかしい。跳ねたり、震えたりする。
原因
衣装とアバターの両方に、同じボーンを動かす PhysBone が入っていることがあります。
直し方
衣装の説明書を見て、どちらの PhysBone を使うかを決め、要らないほうを消すかオフにします。

メニューが出ない

起きること
Expressions Menu に、作ったトグルが出てこない。
原因
Menu Installer が無いか、トグルのオブジェクトがアバターの外にあります。メニューの項目数がいっぱいのこともあります。
直し方
トグルをアバターの子に置き、Menu Installer が付いているかを確かめます。再生して Gesture Manager でも確かめます。

服がピンク色になる

起きること
衣装の服が、ピンク一色で表示される。
原因
衣装が使っているシェーダーが、プロジェクトに入っていません。
直し方
説明書に書かれたシェーダー（lilToon など）を入れます。入れたあとも直らないときは、マテリアルのシェーダーを選び直します。

対応していないアバターに着せたい

起きること
好きな衣装が、自分のアバターに対応していない。
原因
体の形やボーンの位置がちがうため、そのままでは合いません。
直し方
Outfit Root の「位置を元アバターに合わせてリセット」で大まかに合わせてから、ボーンの位置や大きさを少しずつ直します。合わせるためのツールもあります。手間がかかるので、改変に慣れてからがおすすめです。利用規約で非対応のアバターへの改変が認められているかも確かめます。

気をつけること

  • 衣装やアバターのプレハブは、Unpack しなくて大丈夫です。Unpack しないほうが、更新を入れたときに楽です。
  • 元の服を消すのではなく、オフにしておくと、あとで戻せます。
  • 衣装を足すと、ポリゴン数やマテリアル数が増えて、パフォーマンスランクが下がることがあります。アップロードの前に確かめます。
  • 改変の前に、プロジェクトのバックアップを取っておくと安心です。

まとめ

  • 衣装は、対応アバター用のプレハブを、アバターの子に置きます。
  • 右クリックの Setup Outfit で、Modular Avatar がボーンを自動でまとめます。元のデータはこわれません。
  • 体の突き抜けは、MA Shape Changer で、衣装がオンのときだけ体を縮めます。
  • Create Toggle で、メニューから服を着たり脱いだりできます。
