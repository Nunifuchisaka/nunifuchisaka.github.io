アバター改変の解説 第5回

Quest・スマホ対応

Quest やスマホの人には、パソコン用のアバターは見えません。見てもらうには、軽くした別の版（Android 版・iOS 版）を、同じアバターにアップロードします。なぜ別の版が要るのか、何が使えないのか、どう作るのかを解説します。

こんなときに読んでください

  • Quest の友だちから、自分のアバターがぼやけた姿やロボットに見えると言われた。
  • パソコン用に改変したアバターを、Quest やスマホの人にも見てもらいたい。
  • Quest 版をアップロードしたのに、見えないと言われる。

なぜ別の版が要るのか

VRChat は、パソコン（Windows）と、Android（Quest やスマホ）、iOS（iPhone や iPad）で動きます。アバターはそれぞれ別の形で作ってアップロードします。Quest やスマホは、パソコンよりずっと性能が低いので、重いものや一部の部品は使えません。

アップロードするときは、同じアバター（同じ Blueprint ID）に、パソコン版と Android 版を並べて入れます。見る人の機器に合う版が、自動で選ばれます。

Quest の人からは、どう見えるか

Android 版がある
Android 版のアバターが見えます。ただし、ランクが低いと見えないことがあります（下の「ランクの厳しさ」）。
パソコン版しかない
VRChat が自動で作ったインポスター（板を組み合わせた、ぼやけた身代わり）が見えます。インポスターを切っていると、その人が選んだフォールバックのアバター（ロボットなど）になります。
インポスターについて
インポスターは、VRChat のサイトの自分のアバターのページで、作り直すこともできます。人型のアバターだけに対応しています。あくまで身代わりなので、表情や服のオンオフは伝わりません。

VRChat の資料：Impostors（新しいタブで開きます）

Quest・スマホで使えないもの

Quest・スマホのアバターでは、次のものが使えません。入っていると、消されたり、動かなかったりします。

  • シェーダーは、VRChat が用意した「VRChat/Mobile」のものだけです。lilToon などのシェーダーは使えません。
  • ライト（Light）、カメラ、Cloth、音（Audio Source）、Rigidbody や Collider などの物理の部品は、まったく動きません。
  • Unity の Constraint は動きません。VRChat Constraint を使います。Dynamic Bone も動かないので、PhysBone を使います。
  • パーティクルは、きびしく制限されます。
  • Android 版のアバターは、圧縮したあとで 10MB を超えるとアップロードできません。5〜8MB を目安にします。

VRChat の資料：Android Content Limitations（新しいタブで開きます）

使えるシェーダー

Toon Lit平らな色の、アニメ調のアバターに。設定が少なく、とても軽いです。

Matcap Lit金属のような光るところに。
Diffuse など色だけを出す、いちばん簡単なものです。

半透明（髪の毛先のぼかしなど）は使えないので、不透明か、くっきり切り抜く形にします。マテリアルの「Enable GPU Instancing」は、オンにしておきます。

  1. Shader の一覧から「VRChat/Mobile」を選び、その中のシェーダーにします。ほかのシェーダーのままだと、Quest ではピンク色や、見えない姿になります。
  2. 軽くするために、オンにしておきます。

ランクの厳しさ

Quest・スマホでは、パフォーマンスランクの基準が、パソコンよりずっと厳しくなります。そのうえ、Quest・スマホの人は、はじめの設定では Medium までしか見えません。Poor と Very Poor のアバターは、インポスターかフォールバックになります。

見る人は、設定で Poor まで見えるようにはできますが、Very Poor は見えるようにできません（相手を選んで「Show Avatar」を押せば、1人ずつは見えます）。Quest 版は Medium 以上を目指します。

VRChat の資料：Avatar Performance Ranking System（新しいタブで開きます）

まず、販売ページを確かめる

多くのアバターや衣装は、販売ページに「Quest 対応」と書かれていて、Quest 用のデータが入っています。入っていれば、それを使うのがいちばんの近道です。Quest 用のプレハブを置いて、同じように改変します。

Quest 用のデータが無いときは、自分で軽くします。衣装やアクセサリーを足すほど重くなるので、Quest 版はシンプルな姿にするのがおすすめです。

Quest 版を作る手順

  1. Unity に「Android Build Support」が入っているかを確かめます。入っていなければ、Unity Hub で足します（第1回 Unity Hub で Unity を入れる）。
  2. パソコン版のアバターを複製して、Quest 用にします。元のアバターに手を入れないので、パソコン版はそのまま残せます。
  3. VRChat SDK のコントロールパネル（VRChat SDK → Show Control Panel）の「Builder」タブで、Platform を「Android」に切り替えます。確認が出たら進めます。
  4. Quest 用のアバターのマテリアルを、すべて「VRChat/Mobile」のシェーダーに変えます。マテリアルを分けておくと、パソコン版の見た目を壊しません。
  5. 使えない部品（ライト、Cloth、音、Unity の Constraint など）を消します。SDK のコントロールパネルに出る警告やエラーも見ます。
  6. ポリゴン、マテリアル、PhysBone を減らして、ランクを Medium 以上にします。
  7. パソコン版と同じ Blueprint ID にアップロードします。同じプロジェクトでアバターを複製したなら、Pipeline Manager の ID もそのまま入っています。
  8. Quest の人に見てもらうか、自分の Quest で確かめます。
  1. アップロードする先を選びます。印を付けたものを、まとめてアップロードできます。いま開いている先と違うものを選ぶと、切り替えの確認が出ます。
  2. 押すと、選んだ先ごとにビルドしてアップロードします。Android に切り替えると、はじめは全部を読み込み直すので、時間がかかります。

手間を減らすツール

  • VRChat の資料では、パソコン版と Quest 版で設定を切り替える「EasyQuestSwitch」が紹介されています。VCC から入れられます。
  • パソコン版のアバターを複製して、Quest 用のマテリアルやテクスチャを作り、使えない部品を消すツール「VRCQuestTools」もあります。ただし、ランクまでは軽くしてくれないので、そのままでは Very Poor になりがちです。
  • パソコン版と Quest 版で別々のアバターを用意したときは、SDK の「Per-Platform Override」で、1つのアバターにまとめてアップロードできます。

パソコン版と Quest 版でそろえること

  • ボーンの組み立て（Armature）はそろえます。頭、手、足などの大事なボーンの名前や並び、Hips の大きさと向きを変えると、ほかの機器から見たときに、おかしな動きになります。髪やスカートのボーンを減らすのはかまいません。
  • Expression のメニューとパラメーターも、そろえておくと安心です。片方だけにある服のオンオフなどは、もう片方の人からは変わって見えません。

iOS（iPhone・iPad）

iOS 版の VRChat もあります。作り方は Android 版とほぼ同じで、使えないものや基準も同じです。iOS 版を作るには、Unity Hub で「iOS Build Support」を足して、Platform で「iOS」を選んでアップロードします。

iOS 版が無いアバターは、iOS の人からはインポスターに見えます。

よくある困りごと

ピンク色になる

起きること
Quest の人から、アバターの一部や全部がピンク色に見えると言われる。
原因
Quest 版に、VRChat/Mobile 以外のシェーダーのマテリアルが残っています。
直し方
Quest 用のアバターのマテリアルを、1つずつ VRChat/Mobile のシェーダーに変えます。衣装やアクセサリーのマテリアルも見落とさないようにします。

ぼやけた姿・ロボットに見える

起きること
Quest の人から、ぼやけた姿（インポスター）やロボットに見えると言われる。
原因
Android 版がアップロードされていないか、パソコン版と別のアバター（別の Blueprint ID）にアップロードしています。
直し方
Platform を Android にして、パソコン版と同じ Blueprint ID にアップロードします。VRChat のアバターの詳細で、Android 版があるかを確かめます。

Quest 版があるのに見えない

起きること
Android 版をアップロードしたのに、Quest の人からは見えない。
原因
ランクが Poor か Very Poor です。Quest・スマホの人は、はじめの設定では Medium までしか見えません。
直し方
ポリゴン、マテリアル、PhysBone などを減らして、Medium 以上にします。SDK のコントロールパネルで、Android のときのランクを確かめます。

切り替えにとても時間がかかる

起きること
Platform を Android に切り替えると、何十分も待たされる。
原因
はじめて切り替えるときは、テクスチャなどを全部読み込み直すためです。
直し方
はじめの1回は待ちます。2回目からは速くなります。切り替えの途中で Unity を閉じないでください。

片方だけ更新してしまった

起きること
パソコン版だけ改変してアップロードしたら、Quest の人からは前の姿のまま見える。
原因
Android 版を、アップロードし直していません。版ごとに別々に入っています。
直し方
Quest 版にも同じ改変をして、アップロードし直します。Platform で Windows と Android の両方に印を付けると、まとめてアップロードできます。

気をつけること

  • VRChat は、Very Poor の Quest・スマホのアバターを、これから先は使えなくするかもしれないと案内しています。Quest 版は Very Poor にしないでください。
  • Quest 版は、自分の Quest か、Quest の友だちに見てもらって確かめます。パソコンの Unity では、Quest での見た目はわかりません。
  • 改変したものを Quest 版にするときも、アバターや衣装の利用規約を守ります。Quest 版の改変やアップロードを認めているかも確かめます。

まとめ

  • Quest やスマホの人に見てもらうには、Android 版（iOS 版）を、パソコン版と同じ Blueprint ID にアップロードします。
  • シェーダーは VRChat/Mobile だけ。ライトや Cloth、音などは使えません。
  • Quest・スマホの人は、はじめは Medium までしか見えないので、Medium 以上を目指します。
  • まずは販売ページで、Quest 用のデータがあるかを確かめます。
