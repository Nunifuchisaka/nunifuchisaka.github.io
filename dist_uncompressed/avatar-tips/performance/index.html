パフォーマンスランクと軽量化

アップロードしたら Very Poor になった。衣装を足したら、ランクが下がった。パフォーマンスランクの決まり方と、ほかの人からの見え方、ランクを上げる（軽くする）方法を解説します。

公開 2026年11月3日 · パソコン版（PC）の VRChat の話です。上限の数は、VRChat の公式ページ（2026年10月21日更新）によります。

こんなときに読んでください

  • アップロードしたら、ランクが Very Poor だった。
  • 衣装やアクセサリーを足したら、ランクが下がった。
  • イベントで、Very Poor のアバターは控えてと言われた。
  • ほかの人から、自分のアバターが別の姿に見えていると言われた。

パフォーマンスランクとは

パフォーマンスランクは、アバターがどれくらい重いか（パソコンに負担をかけるか）を、5段階で表したものです。ポリゴンの数やマテリアルの数など、項目ごとに上限が決まっています。

Excellent
いちばん良いランクです。
Good
十分に良いランクです。目指すならここです。
Medium
名前のわりに、十分です。ここまで来ていれば、困ることはあまりありません。
Poor
少し直したほうがよいランクです。
Very Poor
重いアバターです。上限が無いので、とても重いこともあります。

アバターのランクは、いちばん低い項目のランクになります。ほかの項目がすべて Excellent でも、1つでも Very Poor の項目があれば Very Poor です。

VRChat は、Good を目指し、むずかしければ Medium で十分と案内しています。

ランクは、アバターに入っている部品の数を数えて決めるだけの目安です。シェーダーやアニメーションの重さは見ていません。ランクがすべてではありませんが、重いアバターを見つけるには役に立ちます。

ほかの人からどう見えるか

見る人は、VRChat の「Safety」のタブの右上にある「Performance Options」で、どのランクまで表示するか（Minimum Displayed Performance Rank）を決められます。パソコン版の初めの設定は「Very Poor」で、どのランクのアバターもそのまま見えます。見る人が「Medium」や「Poor」にすると、それより低いアバターは、次のように変わって見えます。

  1. パソコン版の初めの設定は「Very Poor」です（どのアバターもそのまま見えます）。「Medium」にすると、Poor と Very Poor のアバターは、部品が外されたり、代わりの姿になったりします。
超えた項目見え方
三角形の数、テクスチャのメモリ、メッシュの数、マテリアルの数、ボーンの数アバターが、代わりの姿（Fallback）になる
PhysBone や Contact の数PhysBone と Contact がすべて外される（髪などが揺れなくなる）
パーティクル、ライト、音などその部品がすべて外される

スマホや Quest では、初めから「Medium」までしか表示されず、Very Poor を表示する設定は選べません。くわしくは第5回で扱います。

人の多いイベントやグループでは、Very Poor のアバターを控えるように言われることがあります。仲のよい人と遊ぶときは Very Poor のアバターを使うとしても、人の多い場所向けに、軽いアバターも用意しておくと安心です。

オフにしている物も数えます。メニューで出し入れする衣装やアクセサリーも、オフのまま入っていれば、メッシュやマテリアル、PhysBone の数に入ります。

ほかにも、大きさ（Bounds Size）、Constraint、Animator の数などの項目があります。すべての項目は、VRChat の Performance Ranks のページ（新しいタブで開きます）で見られます。

ランクを見る場所

ランクは、アップロードする前に Unity で、アップロードしたあとに VRChat の中で見られます。

Unity（アップロードする前）

  1. Unity の上のメニューの「VRChat SDK」→「Show Control Panel」を開きます。
  2. 「Builder」のタブで、アバターを選びます。
  3. パフォーマンスの欄に、全体のランクと、ランクを下げている項目が出ます。
  1. アバター全体のランクです。いちばん低い項目のランクになります。
  2. 三角形の数は Good の範囲です。ここを減らしても、全体のランクは上がりません。
  3. ランクを下げている項目です。ここを減らすと、ランクが上がります。

VRChat の中（アップロードしたあと）

  1. メインメニューの「Avatars」で自分のアバターを選び、左下の「Avatar Stats」を押します。
  2. ほかの人のアバターは、クイックメニューを開いてその人を選び、「Show Avatar Stats」を押すと見られます。
  3. 文字の色は、その項目のランクを表しています。

なぜ軽くしたほうがよいか

アバターは、ほかの人のパソコンでも描かれます。重いアバターは、まわりの人のパソコンにも負担をかけ、フレームレート（なめらかさ）を下げます。人が集まる場所では、その分が積み重なります。

とくに、マテリアルとメッシュの数が多いと、描くための命令（ドローコール）が増えます。三角形の数より、こちらが効いていることもよくあります。

テクスチャのメモリが多いと、グラフィックボードのメモリ（VRAM）が足りなくなり、カクついたり、落ちたりする原因になります。

項目ごとのランク

  • 三角形の数：69,000 → Good
  • テクスチャのメモリ：120 MB → Poor（いちばん低い）
  • スキンメッシュの数：6 → Medium
  • マテリアルの数：12 → Medium
  • ボーンの数：300 → Poor（いちばん低い）
  • PhysBone の数：20 → Poor（いちばん低い）
  • PhysBone で動くボーンの数：180 → Poor（いちばん低い）

軽くする方法

効きやすい順に並べています。元のアバターを直接けずる前に、まず 1 と 2 を試してみてください。

1. Avatar Optimizer（AAO）を入れる
アップロードするときに、見た目を変えずに自動で軽くしてくれるツールです。使っていない部品を消す、メッシュをまとめる、PhysBone をまとめるなどを行います。元のアバターは書き換えません。入れ方は、下の「AAO で軽くする」を見てください。
2. 使わない衣装を消す
オフにしている物も数えられます。着替えない衣装やアクセサリーは、オフにするだけでなく、アバターから消します（アップロード用のアバターを複製して、そちらで消すと安心です）。
3. メッシュとマテリアルをまとめる
メッシュをまとめるツールや、テクスチャを1枚にまとめて（アトラス化して）マテリアルを減らすツールがあります。マテリアルとメッシュが減ると、ドローコールが減ります。
4. PhysBone を減らす
揺れなくてもよいところの PhysBone を外したり、同じ設定のものを1つにまとめたりします。動くボーンの数も減らせます。
5. テクスチャを小さくする
テクスチャを選び、Inspector の「Max Size」を小さくします（2048 を 1024 にすると、メモリは約4分の1）。目のテクスチャなど、細かいところが必要なものは残します。「Use Crunch Compression」はダウンロードの大きさを減らしますが、テクスチャのメモリは減りません。
6. ポリゴンを減らす
ポリゴンを減らすツールもありますが、見た目が崩れやすいので最後の手段です。三角形の数が Good の範囲なら、ほかの項目を先に直します。

AAO で軽くする

AAO は、元のアバターを書き換えず、Play を押したときと、アップロードするときに軽くします。いらなくなったら、部品を外すだけで元に戻ります。

  1. AAO のページ（新しいタブで開きます）のリンクから、anatawa12 さんのリポジトリを VCC か ALCOM に足します（足し方は第1回を見てください）。
  2. プロジェクトの管理画面で「AAO: Avatar Optimizer」を入れます。
  3. Hierarchy でアバターのいちばん上（VRC Avatar Descriptor がある物）を選びます。
  4. Inspector の「Add Component」で「AAO Trace And Optimize」を探して足します。初めの設定のままで大丈夫です。
  5. Play を押して、見た目やギミックが変わっていないかを確かめてから、アップロードします。Builder のランクには、AAO で軽くしたあとの数が出ないことがあるので、アップロードしたあとに VRChat の中の「Avatar Stats」で確かめます。

第1回 ツールやシェーダーを足す

よくある困りごと

衣装を足したら Very Poor になった

起きること
衣装をいくつか入れて、メニューで切り替えられるようにしたら、Very Poor になった。
原因
オフの衣装も数えられるため、メッシュとマテリアル、PhysBone の数が増えています。
直し方
着替えない衣装を消します。AAO の Trace And Optimize を入れると、メッシュがまとめられて減ることもあります。

PhysBone の項目だけ Poor

起きること
ほかは Good なのに、PhysBone の数や、動くボーンの数で Poor になる。
原因
衣装ごとに、髪や服の PhysBone が入っています。
直し方
揺れなくてもよい PhysBone を外すか、AAO にまとめてもらいます。

テクスチャのメモリが多い

起きること
Texture Memory が 150 MB を超えて、Very Poor になる。
原因
4096 などの大きなテクスチャが、たくさん入っています。
直し方
目立たない部分のテクスチャから、Max Size を 2048 や 1024 に下げます。

ほかの人には別の姿に見えている

起きること
自分では見えているのに、ほかの人には代わりの姿（Fallback）や、ロボットの姿で見えている。
原因
見る人が、表示するランクを Medium などにしているか、スマホや Quest で見ています。
直し方
ランクを上げると、見てもらえる人が増えます。スマホや Quest の人向けには、対応版のアバターを用意します（第5回）。

気をつけること

  • けずる前に、アバターのフォルダを書き出すか、プロジェクトのバックアップを取ってください。けずった部分は戻せないことがあります。
  • 直接けずるより、AAO のように元を書き換えないツールを先に使ってください。
  • ランクは目安です。Medium なら十分です。ランクを上げるために、気に入っている見た目まで崩す必要はありません。
  • ランクの上限は、VRChat が変えることがあります。新しい数は、VRChat の公式ページで確かめてください。

まとめ

  • アバターのランクは、いちばん低い項目のランクで決まります。
  • オフにしている衣装も数えられます。使わない物は消します。
  • まず AAO の Trace And Optimize を入れ、次にマテリアル、PhysBone、テクスチャを見直します。
  • Good を目指し、むずかしければ Medium で十分です。
