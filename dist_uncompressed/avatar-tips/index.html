アバター改変の解説

アバター改変でつまずきやすいところを、1回に1つずつ、仕組みと直し方まで解説する連載です。

Unity（Built-in Render Pipeline）で作る VRChat のアバターを前提に書いています。

  1. 第7回 Quest・スマホ対応 Quest やスマホの人に見てもらうには、軽くした Android 版が要ります。使えないもの、ランクの基準、作り方をまとめました。 2026年11月3日
  2. 第6回 パフォーマンスランクと軽量化 アバターのランクは、いちばん低い項目で決まります。上限の表と、AAO などで軽くする方法をまとめました。 2026年11月3日
  3. 第5回 衣装を着せる 買った衣装を Modular Avatar で着せる手順と、体の突き抜けの直し方、メニューで服をオンオフする方法をまとめました。 2026年11月3日
  4. 第4回 アップロードのしかた 買ったアバターを VRChat にアップロードするまで。シェーダーの順番、Builder の見方、更新と Blueprint ID をまとめました。 2026年11月3日
  5. 第3回 VCC・ALCOM・Unity の入れ方 改変に要る Unity Hub と Unity、VCC と ALCOM。それぞれの役目とどちらを選ぶか、入れる手順をまとめました。 2026年11月3日
  6. 第2回 Unity と VRChat で見た目が変わる Unity で整えた表情や体の形が、VRChat では元に戻る。その多くは、FX の Animator が BlendShape を書き換えているためです。 2026年11月3日
  7. 第1回 Render Queue（描画の順番） 半透明の髪や服が角度で消える、水面に隠れる。その多くは、描く順番の数字で直せます。 2026年11月2日

これから回を増やしていきます。
