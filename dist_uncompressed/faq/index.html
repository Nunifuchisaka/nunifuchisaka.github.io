買う前に

Quest で使えますか？

DeepFrostIce・SpiderWeb・餓者髑髏・Regret は PC 専用で、Quest では使えません（DeepFrostIce と SpiderWeb は画面の歪み〈GrabPass〉を、餓者髑髏は Final IK を使うため）。ほかの制作物は、説明書の動作環境を見てください。

関係する制作物 DeepFrostIceSpiderWeb餓者髑髏 -Gashadokuro-Regret

アバターや衣装は付いてきますか？

付いてきません。商品の紹介に使っているアバターや衣装は含まれません。GlossySkin も、マスク画像とおまけのギミックだけで、凪 本体やマテリアルは含まれません。

関係する制作物 餓者髑髏 -Gashadokuro-RegretGlossySkin

ほかのアバターでも使えますか？

GlossySkin は 凪 -Nagi- の肌の UV に合わせて描いているので、凪 専用です。HeartBeat は Chest ボーンのあるアバターが前提です。Regret は、付けたい部位の骨が Humanoid に割り当てられている必要があります。

関係する制作物 GlossySkinHeartBeatRegret

入れるとき

Modular Avatar は必要ですか？

HeartBeat・SpiderWeb（1.15 以降）・餓者髑髏・Regret には必要です。入れないままアップロードすると動きません。GlossySkin は、おまけのスライダーを使うときだけ必要です。

関係する制作物 HeartBeatSpiderWeb餓者髑髏 -Gashadokuro-RegretGlossySkin

lilToon は必要ですか？

餓者髑髏（2.3 以降）と Regret には必要です。マテリアルに使っています。GlossySkin は 凪 に付いている lilToon を使うので、別に入れなくて大丈夫です。

関係する制作物 餓者髑髏 -Gashadokuro-RegretGlossySkin

プレハブはどこに置けばいいですか？

SpiderWeb・餓者髑髏・Regret・GlossySkin のおまけのスライダーは、アバターのいちばん上（ルート）の直下に置きます。餓者髑髏は、ルートの直下にないと「Fit To Avatar」が押せません。HeartBeat は、どこに置いても動きます。

関係する制作物 SpiderWeb餓者髑髏 -Gashadokuro-RegretGlossySkinHeartBeat

どの Unity で確かめていますか？

GlossySkin・餓者髑髏・Regret は Unity 2022.3.22f1 で確かめています。餓者髑髏と Regret は、VRChat SDK 3.10.5、Modular Avatar 1.18.7、lilToon 2.4.1 でも確かめています。

関係する制作物 GlossySkin餓者髑髏 -Gashadokuro-Regret

VRChat の中で

ほかの人に見えない・聞こえないことがあります

相手のセーフティ設定によります。HeartBeat は、相手が Contact を切っていると鳴りません。餓者髑髏の炎は、シェーダーを非表示にしている人には見えません。

関係する制作物 HeartBeat餓者髑髏 -Gashadokuro-

ワールドによって見え方が変わります

ワールドの作りに左右されます。DeepFrostIce は、リフレクションプローブの無い場所では反射が暗くなります。SpiderWeb の花びらや Regret の骨は、当たり判定の無い床を通り抜けます。餓者髑髏は、狭いワールドでは壁や天井にめり込みます。

関係する制作物 DeepFrostIceSpiderWebRegret餓者髑髏 -Gashadokuro-

思っていないときに動いてしまいます

手の形やジェスチャーで動くものは、物を掴んだときにも動くことがあります。餓者髑髏は、両手で物を1.5秒以上掴むとブレスが出ます。SpiderWeb は、体格によっては腕組みや拍手で胸の前のセンサーが反応します。

関係する制作物 餓者髑髏 -Gashadokuro-SpiderWeb

Regret の骨が拾えなくなりました

メニューで「Show」をオフにしてからオンにすると、元の部位に戻ります。

関係する制作物 Regret

ツール

Mac で使えますか？

KeyDisplay は Windows と macOS で使えます。ImageGetter・PublicWalker・DeskCinema は Windows 専用です。NuniAvatarToolkit は Blender のアドオンです（Blender 4.2 以降）。

関係する制作物 KeyDisplayImageGetterPublicWalkerDeskCinemaNuniAvatarToolkit

「Windows によって PC が保護されました」と出ました

署名していない個人制作のソフトに出る SmartScreen の警告で、異常ではありません。「詳細情報」→「実行」で進めます（PublicWalker の説明書より）。

関係する制作物 PublicWalker

macOS で KeyDisplay にキーが出ません

「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」で、KeyDisplay を許可してください。Blender や Unity の判定には「画面収録」の許可も要ることがあります。

関係する制作物 KeyDisplay

更新と問い合わせ

新しい版はどう入れますか？

BOOTH の購入履歴から、新しい版をダウンロードし直します。PublicWalker は、アプリの「更新を確認」から BOOTH を開けます。NuniAvatarToolkit は、アドオンを無効にしてから新しい ZIP をインストールし、もう一度有効にします。

関係する制作物 PublicWalkerNuniAvatarToolkit

困ったときは、どこに聞けばいいですか？

それぞれの説明書に書かれた窓口へお願いします。PublicWalker は、diagnostics.log を添えて BOOTH のメッセージから送ってください。GlossySkin のことを、凪 の作者の rio3d 様へ送るのはおやめください。

関係する制作物 PublicWalkerNuniAvatarToolkitGlossySkin
