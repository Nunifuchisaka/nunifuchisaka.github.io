Always-on Windows desktop app

Don't walk into the same instance twice.

When you're hopping between public VRChat instances, instance numbers are just digits — "#12345" doesn't tell you whether you were just there. VRC PublicWalker watches your VRChat logs, keeps a visit history, and warns you — in an always-on-top window and an optional XSOverlay notification — the moment you walk back into somewhere you've already been.

FEATURES

Stop comparing digits by eye.

VRC PublicWalker watches your VRChat logs and records every visit. When you walk back into an instance you've already visited, it tells you — in the window and over XSOverlay.

Always-on-top, big numbers

Your current location and a list of recently visited instances stay in an always-on-top window. Instance numbers are shown large, so you can compare them against a world list at a glance.

Revisit notifications

Walk into an instance you've already visited, and the window shows "#12345 was also visited 5 min ago." Optional XSOverlay notifications mean you'll notice even in VR.

Adjustable threshold

Change "how many minutes counts as a revisit" anytime (1–1440 minutes, default 60). Edit the number at the top of the window and it applies immediately.

Leave detection, too

Leave a world, and the stay-time counter stops while the number dims. You can tell at a glance whether you're still there.

Two detection modes

Choose OSC sync, which catches the moment you move using VRChat's OSC output, or Log watching, which polls your logs on an interval. Switch anytime with a radio button.

Visit history saved locally

Your visit history keeps living on your PC. VRChat's own logs are deleted after 24 hours, but your records stay put, so the revisit rule survives an app restart.

Make it your own

Choose from seven color themes, and fine-tune the number size and background opacity — handy for VR-overlay-style setups too.

Five languages

The interface is available in Japanese, English, Korean, Simplified Chinese, and Traditional Chinese. Switch anytime from the Settings tab.

Never connects to the internet

All traffic stays on your own PC (OSC in from VRChat, notifications out to XSOverlay). No update checks, no external connections, ever.

GET STARTED

Ready in three steps.

Install it, then just launch VRChat.

Run the installer

Run the installer downloaded from BOOTH and follow the Windows installer to finish installation.

Launch VRChat and join a public instance

Before or after launching VRC PublicWalker — either order works. Any log already on disk at launch is picked up automatically.

See the number appear in the list

The instance number appears in the window's list. Walk into the same instance again, and you'll get a notification.

Using VR gear? If you want to notice a revisit while wearing your headset, connect it to XSOverlay (Steam, sold separately).

NOTES

Before you begin

Windows only

Requires the WebView2 runtime, which comes preinstalled on Windows 11 and updated Windows 10.

XSOverlay is optional

You don't need it — the desktop window alone works fine on its own.

About SmartScreen warnings

Because the executable isn't code-signed, Windows may show a warning during installation. This is normal for independently published software, not a sign of a problem.

Depends on VRChat's own behavior

Detection works by reading the log files VRChat writes, so changes to VRChat's own logging could break it.
